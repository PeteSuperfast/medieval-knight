# design: World Map (ทุ่งเขียว → หิมะ) — สำหรับ blender-artist ทำ blockout
อ้างอิง: requirement.md, ref_world_map.png, style.md (faceted low-poly), vision.md (≤ 380x380 ม.)

## 1. เป้าหมายผู้เล่น
เดินทางจากทุ่งหญ้าอบอุ่นทางมุมใต้-ตะวันตก ผ่านแม่น้ำ ป่าสน ปีนหน้าผาหิน ไปจบที่ดินแดนหิมะและปราสาทน้ำแข็งบนยอดเขาทางเหนือ-ตะวันออก
ดูแผนที่แล้วต้องรู้ทันทีว่า "เขียวอุ่น → เย็นขาว" และมีเส้นทางชัดเจนไปหาปราสาท
งานรอบนี้ = blockout + preview ขออนุมัติ ยังไม่เข้าเกม

## 2. ระบบพิกัด
- ขนาดแมพ 380 x 380 ม. มุม SW = (E 0, N 0), มุม NE = (E 380, N 380); +E = ตะวันออก (ขวา) +N = เหนือ (บนจอ top)
- Z = ความสูงจากระดับน้ำทะเลสมมติ 0 ม.
- (ตอนเข้าเกมจริงโค้ดใช้ origin กลางแมพ: x = E-190, z = N-190 — ไม่ใช่งานรอบนี้ แต่ให้จัดวางจุดตรงกลาง (190,190) ไม่ใส่ของใหญ่ขวางตรงๆ เผื่อเว้นสนาม)
- ขอบแมพ: ตัดเป็นแท่งเห็นชั้นดิน/หินด้านข้าง (style.md) ฐานสูง 12 ม. ใต้ระดับ 0 ไม่ต้องมีน้ำนอกแมพ

## 4. แม่น้ำ สะพาน น้ำตก ทะเลสาบ ปราสาท
- **แม่น้ำ (น้ำ #1594BB)** กว้าง 10–14 ม. เส้นกลาง: (0,100) → (40,112) → (75,95) → (95,88) → (120,65) → (135,40) → (150,0) ออกขอบใต้ ตลิ่งหินเตี้ย 1 ม. บางช่วง
- **สะพานหลัก S1 (95,88)** ไม้โค้งเล็กน้อย ยาว 16 ม. กว้าง 4 ม. ทางหลักข้าม; **สะพานรอง S2 (128,48)** ไม้สั้น 12 ม. ข้างกังหันลม (ตกแต่ง ไม่อยู่บนเส้นทางหลัก)
- **ทะเลสาบน้ำแข็ง L (320,270)** รัศมีประมาณ 30x22 ม. ผิวแบน Z 50 สีน้ำแข็ง; ขอบด้านใต้ปล่อยเป็นธารสั้นไปหน้าผา
- **น้ำตก W (305,235)** กว้าง 14 ม. สูง 20 ม. (Z 50 → 30) ใช้แผ่นเหลี่ยมซ้อน 3–4 ชั้น สีน้ำ + น้ำแข็งสว่าง; ที่เชิงเป็นแอ่งน้ำ #1594BB ไหลต่อเป็นธารเล็กไปทางใต้-ตะวันออกจบที่ขอบแมพ (ทำให้สั้นๆ)
- **สะพานเล็กน้ำแข็ง/ไม้ S3 (330,205)** ข้ามธารใต้น้ำตก 8 ม.
- **ปราสาทน้ำแข็ง K (340,340)** ฐานกว้าง ~40 ม. สูงรวม ~45 ม. บนยอดเขา (ยอดสุด Z ~100); หอสูง 5 แท่ง (กลาง 1 สูงสุด + มุม 4) ยอดแหลมเหลี่ยม, กำแพงเตี้ยล้อม, ประตูหน้าหันใต้-ตะวันตกต่อเส้นทาง, หน้าต่าง emission เหลืองส้ม 6 จุด

## 8. Triangle budget
- เป้าหมายทั้งฉาก **≤ 350,000 tri** (blockout จริงน่าจะ ~150–250k)
- ภูมิประเทศ (terrain mesh เป็นแผ่นเหลี่ยม flat shading): ≤ 60,000 tri
- น้ำ+น้ำตก+ทะเลสาบ: ≤ 8,000 | ปราสาท ≤ 3,000 | ภูเขาฉากหลังรวม ≤ 6,000
- ต่อชิ้น (ของวาง): ≤ 500 tri; ต้นไม้/ต้นสน ≤ 100 tri; ก้อนหินเล็ก ≤ 60; ชิ้นเด่น (บ้าน กังหัน ถ้ำ) ≤ 500
- ของที่ซ้ำเยอะ (ต้นไม้ หิน ดอกไม้) ใช้ linked duplicate / instance เพื่อไม่ให้ไฟล์บวม

## 9. มุมกล้อง preview

## 10. Flow การใช้งานภาพ preview

## 11. คำถามที่ยังไม่ชัด (ปูส้ม/พีทเลือกได้ ถ้าไม่ตอบ blender-artist ใช้ค่าตามนี้)
1. ขอเพิ่มสีหิมะ/น้ำแข็ง 4 สี (ข้อ 7) — ค่าเริ่มต้น: ใช้ค่าที่เสนอชั่วคราว
2. พิกัดแมพจริงในเกมเป็นกลางแมพ และมีลานกลางห้ามขวาง (|x|<28, Z -42..32) ซึ่งตรงกับ (190,190) ในผังนี้ — ผังนี้ไม่มีของขวางตรงนั้นอยู่แล้ว (ป่า B ห่างพอ) ตอนเข้าเกมจริงอาจต้องย้ายจุด Start/บอสให้เข้ากับ loop อยู่ดี
3. เส้นทางเดินบนกล้องจริงใช้ "ทางจริง" หรือเป็นแค่เส้นนำ — ค่าเริ่มต้น: ทั้งสอง (ทางดินจริง + เส้นประใน preview)
4. เมฆหมอกใต้หน้าผา — ค่าเริ่มต้น: ทำเป็นระนาบโปร่งง่ายๆ ถ้าไม่ได้ ข้าม
