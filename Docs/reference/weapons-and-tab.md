# ดาบ ช่องอาวุธ และหน้าต่าง Tab

> แยกมาจาก CLAUDE.md (รายละเอียดเต็ม) — ภาพรวมสั้นอยู่ที่ CLAUDE.md

กรอบ ~1000 x 520 กลางจอ: ซ้าย กล่อง EQUIPPED (ไอคอนดาบใหญ่ + ชื่อ / +N / ความหายาก / DMG SPD CRIT REACH) และช่องดาบ 6 ช่องแนวนอน (ความกว้างรวมคงเดิม ช่องละ 97 px) (กรอบสีตามความหายาก: Common เทา / Uncommon เขียว / Rare แดง / Legendary ทอง, ช่องที่ใส่อยู่มีแถบ EQUIPPED, ดาบที่ยังไม่มี = เงาดำ + "???" + บอกที่มา); ขวา CHARACTER / STATS 5 แถว (HP DEF STAMINA SPEED RESISTANCE, n/10 + ผลรวม) / SOUL + Kills (ไม่มีกล่อง SKILLS แล้ว)
ข้อมูลตัวอักษรใน `Hud.RefreshTab` (เรียกเฉพาะตอนเปิด / ทุก ~0.2 วิ) ไอคอนมาจาก `SwordIcons`; ออนไลน์เป็น overlay ไม่หยุดเกม ไม่มีโล่กันเพิ่ม (โล่ 6 วิ `LevelUpProtect` ใช้เฉพาะหน้าต่างเลเวลอัป)

อัศวินมีช่องอาวุธ 1 ช่อง เริ่มด้วย Iron Sword ดาบที่เก็บได้เข้า `knight.inventory` กด Tab แล้วเลือกใส่ โมเดลดาบในมือเปลี่ยนทันที (`Knight.Equip` > `Weapons.BuildModel`)

ตัวเลขการฟันมาจากอาวุธอย่างเดียว (ไม่มีอัปเกรดดาเมจ/ความเร็ว/คริ; ทำใน `Knight.cs` ที่เดียว: `RollDamage`, `CritChance`, `CritMult`, `SwingSpeed`, `Reach`):- ดาเมจ = `KnightAnim.BaseDamage (14) x ตัวคูณท่า (1.0 / 0.9 / 1.2) x Damage ของดาบ x (1 + 0.05 x ระดับ +N)`- Crit chance = `min(75%, 10% + ของดาบ)`, Crit mult = `min(x10, 1.5 + ของดาบ)`- ความเร็วฟัน = `clamp(Speed ของดาบ, 0.4, 4)` (หาร 3 จังหวะแรก; ดึงกลับคงที่)- Reach = ระยะของท่า (2.2 / 2.0 / 2.8) x Reach ของดาบ- สเตตัส 5 ตัว (Progress.cs): HP +20 max (+เติม) · DEF +10 armor, โล่กัน +1.2%, ค่า stamina โล่ -4% · STAMINA +15 max, regen +5% · SPEED เดิน/วิ่ง +3% (ไม่รวมกลิ้ง/ก้าวของท่าฟัน) · RESISTANCE ดาเมจที่รับ -2.5% (หลังโล่ ก่อน armor) และแรงสะท้อน -5%; ใบละ ≤10 แต้ม (24 แต้มที่เลเวล 25)

ดรอป (สุ่มที่ `Game.RollDrop` ที่เดียว):
- สไลม์เขียว 4% / น้ำเงิน 10% / แดง 20% ต่อตัว (`Weapons.SlimeDropChance`) ได้ดาบ 1 ใน 4 เล่มตามสัดส่วน 40.5 / 31.5 / 18 / 10 (Rapier / Greatsword / Fang / Banana Dao, `SlimeDropWeights`)
- Minotaur ดรอป Horned King's Blade 100% ทุกครั้งที่ตาย (`MinotaurDropChance`), หุ่นฟางไม่ดรอป
- ดาบที่ตกลอยหมุนมีวงแหวน + ลำแสงสีตามระดับ เดินเข้าใกล้ 1.25 ม. = เก็บ มีข้อความแจ้งเหนือแถบสกิล อยู่ได้ 90 วินาที (กะพริบ 8 วินาทีสุดท้าย)
- ได้ดาบซ้ำ: ดาบเล่มนั้นเป็น +1 ถึง +5 (ดาเมจของดาบ +5% ต่อขั้น, `Weapons.DamagePerPlus`); ซ้ำอีกหลัง +5 ได้ 15 EXP แทน
- ตายแล้วดาบไม่หาย, F5 ล้างเหลือ Iron Sword และลบของที่ตกอยู่บนพื้น
