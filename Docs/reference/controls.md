# ปุ่มควบคุม

> แยกมาจาก CLAUDE.md (รายละเอียดเต็ม) — ภาพรวมสั้นอยู่ที่ CLAUDE.md

WASD หรือลูกศร เดิน, **Left Shift (ค้าง) = วิ่ง** (x1.5, ไม่กิน stamina), เมาส์ = เล็ง (อัศวินหันตามเคอร์เซอร์เสมอ), คลิกซ้าย / J = คอมโบดาบ (Side Slash > Overhead Chop > Rising Slash > Spin Slash > Thrust; คลิกตัดสินตอนปล่อย <= 0.15 วิ, หน่วง 0.5 วิ ระหว่างฟัน, คลิกซ้อนเข้าคิว 1 คลิก; **phase 6** คลิกที่ 1: ถือ W = Advance Cleave, A/D = Sidestep Slash (ก้าว 2 ม.), S = Shield Jab (ถอย 1.5 ม.); คลิกที่ 3: W = Vault Chop, S = Retreat Slash (ถอย 2.5 ม.); คลิกภายใน 0.35 วิ หลัง dash = Dash Slash (นับเป็นคลิก 1); **ค้างซ้าย 1 วิ แล้วปล่อย = Heavy Strike** 40 ดาเมจ มอนหยุด 0.5 วิ ไม่กิน stamina, ชาร์จเดินช้า 50% โดนตีไม่ยกเลิก, คลิกขวา/dash/สกิล = ยกเลิก, ยกโล่ค้างตอนกด = ไม่ชาร์จ, ชาร์จอยู่ F ชุบเพื่อนไม่ได้),
**Space = dash** (พุ่ง 6 ม. ใน 0.2 วิ ทิศ WASD ไม่กดทิศ = ถอยหลัง, อมตะ 0.5 วิ, กิน stamina 25, คูลดาวน์ 0.8 วิ, ตัดท่าฟัน/สกิลที่กำลังทำ, ห้ามตอนกระโดด Ground Slam), **คลิกขวาค้าง = ยกโล่** (ไม่กิน stamina),
Q Whirlwind, E Dash Thrust, R Shield Bash, F Ground Slam (กระโดดไปที่เคอร์เซอร์),
1 / 2 / 3 หรือคลิกการ์ด = เลือกอัปเกรดตอนเลเวลอัป แล้วเลือกลงแต้มสเตตัส (1 HP / 2 BLOCK / 3 STAMINA),
**Tab** = เปิด/ปิดหน้าต่างอาวุธ + สเตตัส (เล่นคนเดียวหยุดเกม; กด 1-6 หรือคลิกช่อง = ใส่ดาบที่มี), **Esc ตอน Tab เปิด = ปิดหน้าต่างก่อน** (ไม่นับเป็น Esc ออกเมนู), เดินทับของที่ตกบนพื้น = เก็บ, **M** = ระดับเสียง 100% > 60% > 30% > ปิดเสียง,
H โดนตีทดสอบ 20, F5 เริ่มใหม่ (กลับเลเวล 1 ล้างอัปเกรด แต้มสเตตัส ดาบ (เหลือ Iron Sword) และ Soul กลับเมือง; ออนไลน์กดได้เฉพาะ host และรีเซ็ตทุกคน), F1 ซ่อนปุ่มควบคุม, Esc สองครั้ง = กลับเมนู (host กด = ปิดห้อง), Esc ที่หน้าเมนูหลัก = ออกจากเกม


**Single Player จากเมนู (loop ของ phase 1)** — ปุ่มอื่นเหมือนข้างบน ต่างกันตรงนี้: Tab ที่ฐาน = PREPARE (คลิก/Enter ย้ายของ, คลิกขวา = HELD, Q/E สลับฝั่ง), Tab ในโลก = หน้าต่าง Carry (คลิก = ถือ/กิน, คลิกขวา = ทิ้ง), **1 / 2** = ถือ Weapon ช่อง 1 / 2 (ตอนไม่มีการ์ดเลเวลอัป), **C** = กินอาหาร, F5 ปิด, Esc กลางโลก = นับเป็นตาย. phase 2: ที่ PREPARE มีปุ่ม NEW WORLD / OLD WORLDS (ลูกศรลงสุด + ซ้าย/ขวา + Enter), ในหน้ารายการ ขึ้น/ลง + Enter, เดินชนกองของ = หน้าต่างเก็บของ (คลิก/Enter เก็บ, **Q = Take all**, คลิกขวาของใน Pack = ทิ้ง, Esc/Tab ปิด). รายละเอียด: `loop.md`
