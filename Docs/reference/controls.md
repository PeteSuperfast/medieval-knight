**คลิกซ้าย / J = ฟัน** (ตัดสินที่ "ตอนกดลง" ไม่ใช่ตอนปล่อย) วนอัตโนมัติ 1 > 2 > 3 > 1:
- ท่า 1 ฟันเฉียงบนซ้าย>ล่างขวา (ก่อนฟัน/ฟัน/หลังฟัน/ดึงกลับ = 0.20/0.12/0.15/0.25 วิ, พัด 100° ระยะ 2.2 ม., ดาเมจ x1.0, ถลา 0.4 ม.)
- ท่า 2 ฟันกวาดซ้าย>ขวา (0.18/0.16/0.17/0.25, พัด 150° ระยะ 2.0 ม., x0.9)
- ท่า 3 แทง (0.25/0.08/0.15/0.30, แถบกว้าง 0.8 ยาว 2.8 ม. ทะลุหลายตัว, x1.2, ก้าว 1.0 ม.)
- ดาเมจฐาน 14 x ตัวคูณท่า x ดาบ (ไม่มีอัปเกรดดาเมจ/ความเร็ว/คริ — มาจากอาวุธอย่างเดียว); ก่อนฟัน/ฟัน/หลังฟันหารด้วย Speed ดาบ ดึงกลับคงที่; hitbox เปิด 25-85% ของจังหวะ "ฟัน", ศัตรู 1 ตัวโดน 1 ครั้งต่อท่า
- คลิกระหว่างก่อนฟัน/ฟัน/หลังฟัน = เก็บ 1 คลิก ใช้เมื่อ "หลังฟัน" จบ (ข้ามดึงกลับ, ก่อนฟันของท่าถัดไปสั้นลง 30%); คลิกระหว่างดึงกลับ = เริ่มเมื่อดึงกลับจบ; ไม่คลิกต่อใน 0.4 วิหลังดึงกลับ = รีเซ็ตเป็นท่า 1; ยกโล่ค้างตอนกด = ไม่ฟัน; ก่อนฟัน/ดึงกลับเดินช้า 30% ตอนฟัน/หลังฟันถูกขับด้วยท่า

**Space = กลิ้งหลบ** (6 ม. ใน 0.4 วิ ทิศ WASD ไม่กดทิศ = กลิ้งถอยหลัง, อมตะ 0.5 วิ, กิน stamina 25, คูลดาวน์ 0.8 วิ; ตัดท่าฟัน/กินได้ แล้วรีเซ็ตท่า 1; ห้ามกลิ้งใน 2 จังหวะแรกของท่าปัดโล่), ระหว่างกลิ้งคลิกฟันไม่ติด

**คลิกขวาค้าง = ยกโล่** (กิน stamina 10 ต่อครั้งที่รับ ลด 4% ต่อแต้ม DEF; stamina ไม่พอ = รับเต็ม "GUARD BROKEN"; stamina ไม่ฟื้น 0.6 วิ หลังรับ), **ปัดโล่ (parry)**: ยกโล่ ≤0.2 วิ ก่อนโดนท่าเบา = PARRY (กดใหม่ใน 0.5 วิ ไม่มีหน้าต่าง; ศัตรูกระเด็น+สตัน) เล่น motion 4 จังหวะ 0.15/0.12/0.25/0.20 วิ (ยกโล่ > ปัดออก + ประกาย #F5C25A > กางแขน > ดึงกลับ; 2 จังหวะแรกตัดไม่ได้ หลังจากนั้นฟัน/กลิ้งตัดได้), ฟันตรงจังหวะ "ฟัน" ของท่าที่ศัตรูท่าเบาฟาด (ศัตรูอยู่ครึ่งหน้า ≤5.5 ม.) = CLASH ไม่เจ็บทั้งคู่, ท่าหนัก (สไลม์แดง, Smash, Charge: เรืองแดง/`!`) ปัดไม่ได้

**F ค้าง 2 วิ = กินอาหาร** (ทุกโหมด ไม่มีกินทันที): loop = กินอาหารชิ้นแรกใน carry (Food ก่อน Supplies); สนาม v1 (-arena/-single) = อาหารบนพื้นในระยะ 1.2 ม.; ยืนนิ่ง HP ต้องไม่เต็ม แถบเขียว #8DB04A เหนือหัว + ข้อความ "Hold F: Eat"; ขัดจังหวะ (ความคืบหน้าหาย อาหารไม่หาย): โดนตี (รวมโล่ลดดาเมจ), กลิ้ง, เดิน, ปล่อย F, คลิกฟัน/ยกโล่ (ฟัน/ยกโล่ทันที), ล้ม, เปิด panel; HP เต็ม = ไม่เริ่ม ขึ้น "HP full"; เพื่อนล้มใน 3 ม. (loop ออนไลน์) = F เป็นชุบเพื่อนแทน

**1 - 5 หรือคลิกการ์ด = เลือกสเตตัสตอนเลเวลอัป** (ขั้นเดียว 5 ใบ: 1 HP / 2 DEF / 3 STAMINA / 4 SPEED / 5 RESISTANCE; แป้นตัวเลขใช้ได้; ใบละ ≤10 แต้ม เต็มแล้วเลือกไม่ได้ panel ไม่ปิด)
