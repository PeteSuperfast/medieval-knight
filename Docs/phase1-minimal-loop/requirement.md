# Phase 1 — loop ขั้นต่ำ (คนเดียว): requirement
> สถานะ: **ร่าง รอพีทยืนยัน** (2026-10-12) — ห้ามส่ง designer/architect/developer จนกว่าจะยืนยัน
> ขอโดย: peatengkrub (372330922122674179) | กรอบ: Docs/vision.md phase 1 | เสาหลัก: 2 เดิมพันจริง, 3 ทุกรอบไม่ซ้ำ (เตรียมทาง)

## เป้าหมาย
เล่นครบ 1 รอบได้ทั้ง "รอด" และ "ตาย":
ฐาน → เตรียมของ → เข้าโลก (biome เดียว = แมพปัจจุบัน) → สู้ → ฆ่าบอสโลก (Minotaur) → กลับฐานพร้อมของ
หรือ ตายในโลก → ของที่พกทั้งหมดหาย → กลับฐานมือเปล่า

## ที่พีทตัดสินแล้ว
1. เริ่มเกมครั้งแรก คลังฐานมีแค่ **Iron Sword เล่มเดียว**
2. ก่อนเข้าโลก **เลือกของที่พกได้ N ชิ้น** (เช่น 1 เล่มถือ + อาหาร)
3. ต้องมีที่เก็บ 3 แบบ: **ช่องอาวุธ, ช่องอาหาร, ช่องสัมภาระ** (ช่องสัมภาระเก็บได้ทุกอย่าง)
4. ตายแล้วของที่พกหายออกจากคลัง **ยังไม่มีให้ไปเก็บคืน** (ทำใน phase 2)
5. **แจก Iron Sword ฟรีเสมอ** ที่ฐาน (ไม่ให้ตัน)
6. เก็บข้ามรอบเฉพาะ **อาวุธในคลังฐาน** — Soul / EXP / เลเวล / การ์ด / สเตตัส เริ่มใหม่ทุกรอบ
7. การเซฟ: ปูส้มแนะนำที่เครื่องผู้เล่นเอง (ดูข้อ "รอยืนยัน")

## ขอบเขต (ต้องทำ)
**ฐาน**
- ที่เรียบๆ (ใช้ลานกลางเดิมได้) ไม่มี NPC ไม่มีร้านค้า ไม่มีบทสนทนา
- หน้าจัดของ: คลัง (ช่องอาวุธ/อาหาร/สัมภาระ) ↔ ชุดที่พกเข้าโลก, ปุ่ม "เข้าโลก"
- Iron Sword แจกฟรีถ้าไม่มีอาวุธเหลือในคลังและในชุดพก (เกิดใหม่ที่ฐานแล้วเห็นเล่มนี้เสมอ)

**ในโลก**
- เริ่มเลเวล 1 ทุกครั้ง พกเฉพาะชุดที่เลือก ของที่เก็บได้ในรอบ (อาวุธ/อาหาร) เข้าช่องที่พก — เต็มแล้วเก็บเพิ่มไม่ได้ (แจ้งผู้เล่น)
- บอสโลก = Minotaur (ตัวเดิมในรังเหนือ) **ฆ่าก่อนถึงกลับได้** ไม่มีทางออกอื่น
- ฆ่าบอสแล้วมีทางกลับฐาน (เช่น portal) ไม่กลับทันทีอัตโนมัติ เพื่อให้เก็บของก่อน

**ผลลัพธ์**
- รอด: ของที่พกอยู่ทั้งหมด (อาวุธ+อาหาร+สัมภาระ) ย้ายเข้าคลัง; ค่า refine +N ของอาวุธติดไปด้วย
- ตาย: ของที่พกทั้งหมดหาย **ถาวร** (ใน phase 1) แล้วกลับฐาน; ของในคลังที่ไม่ได้พกยังอยู่
- ตายแล้ว ไม่มีเกิดใหม่กลางโลกเหมือน v1 (เกม v1 ตายแล้วเกิดใหม่ที่ spawn) — ใน loop ใหม่ ตาย = จบรอบ

**เซฟ**
- เก็บคลังฐาน (อาวุธ/อาหาร/สัมภาระ) เป็นไฟล์เดียว เซฟอัตโนมัติเมื่อกลับฐาน และก่อนเข้าโลก
- ปิดเกมกลางโลก = นับเป็น "ตาย" (กันโกงเซฟ) — **รอยืนยัน** (ดูด้านล่าง)

## ไม่ทำใน phase นี้ (อยู่นอก scope)
- โลกเก่า / ของที่ตกให้เก็บคืน / ความยากเพิ่ม / หมดอายุ 3 ครั้ง → phase 2
- biome เพิ่ม / บอส biome / เกรดอาวุธ Rust→God → phase 3
- co-op ของ loop ใหม่ / knock down / revive → phase 4 (ปุ่ม Host/Join ยังเล่นแบบ v1 ไม่แตะ)
- สกิลตามอาวุธ, อัลติ R, อัปเกรดสกิล, อาวุธใหม่ → backlog
- Soul: ยังไม่มีที่ใช้ → ซ่อนหรือคงไว้เฉยๆ ไม่ผูกกับคลัง (รอพีทตัดสินเรื่อง Soul)
- ร้านค้า/crafting/เนื้อเรื่อง/NPC (อยู่ใน "ไม่ทำ" ของ vision)

## เกณฑ์เสร็จ (ต้องทำให้ได้ทั้งหมด)
1. เมนู Single Player → เข้าฐาน เห็นคลังมี Iron Sword เล่มเดียวในครั้งแรก
2. จัดชุดพก (อาวุธ/อาหาร/สัมภาระ) → เข้าโลก → ในมือเป็นอาวุธที่เลือก
3. ฆ่า Minotaur → กลับฐาน → ของที่พกกลับเข้าคลัง (รวมของที่เก็บได้ในรอบ)
4. ตายในโลก → กลับฐาน → ของที่พกไม่อยู่ในคลัง แต่ของที่ไม่ได้พกยังอยู่ และมี Iron Sword เสมอ
5. ปิด-เปิดเกมใหม่ → คลังยังอยู่ตามเดิม
6. build ผ่าน, selftest 0 FAIL (มีเคสใหม่สำหรับรอด/ตาย/เซฟ), mptest ผ่านเหมือนเดิม
7. ไฟล์เอกสารแต่ละไฟล์ ≤ 10KB

## รอยืนยัน (ปูส้มเสนอค่าเริ่มต้น แก้ได้)
| หัวข้อ | ค่าที่เสนอ | เหตุผล |
|---|---|---|
| จำนวนช่อง **ชุดที่พกเข้าโลก** | อาวุธ 2 (ถือ + สำรอง) / อาหาร 3 / สัมภาระ 4 | พอให้ "เสี่ยง" มีความหมาย ไม่ใหญ่จนไม่เจ็บ |
| จำนวนช่อง **คลังฐาน** | อาวุธ 12 / อาหาร 8 / สัมภาระ 16 | โตได้ในอนาคต (backlog มี "กระเป๋า 8 ช่อง") |
| ที่เซฟ | ไฟล์ในเครื่องผู้เล่น (`persistentDataPath`) | phase 1 เล่นคนเดียว คลังเป็นของผู้เล่นแต่ละคน; ข้อมูล "โลก" (phase 2) ค่อยอยู่ที่ host ตาม vision |
| ปิดเกมกลางโลก | นับเป็นตาย | กัน save-scum; ถ้าพีทอยากให้ใจดีกว่า ให้เซฟตำแหน่งกลางโลกได้ ซึ่งงานใหญ่ขึ้น |
| อาวุธซ้ำ | ใช้กติกา +N เดิม (ชนิดเดียวกัน = refine) ค่า +N ติดข้ามรอบ | ไม่รื้อของเดิม |
| ของในช่องสัมภาระตอนนี้ | มีแค่อาวุธ/อาหาร (ยังไม่มีไอเทมชนิดอื่น) | ช่องสัมภาระเตรียมไว้สำหรับของใหม่ใน phase ถัดไป |
