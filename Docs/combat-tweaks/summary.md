## ต่อสู้
- คลิกซ้าย = คอมโบ หน่วง 0.5 วิ ทุกคลิก (8)
- charge = โจมตีหนัก ดาเมจแรง มอนหยุดโจมตี 0.5 วิ (12-13 ปรับแล้ว)
- คลิกซ้ายค้าง = charge เต็ม 1 วิ (ทดลอง) ดาเมจแรงขึ้น ต่อเป็นคอมโบได้ (3→29)
- ท่าใหม่: dash + คลิก, เดินหน้า + คลิก, ตามทิศ A S W D + จำนวนคลิกในคอมโบ (28) designer เสนอรายการ พีทอนุมัติ

## สกิล
- ผูกกับอาวุธ: ดาบโล่ คลิกขวา = บล็อก (นับเป็นสกิล) unique ต่ออาวุธ (22, 25)
- เอา Q E F ออก อัลติกด R ตาม class (23, 27) class อนาคต mage / assassin / healer-buffer (26)
- อัปเกรดที่เลเวล 5/10/15/20/25 สุ่มสกิลที่มี เสนอ 3 ทางเลือก เพิ่มความสามารถ/สเตตัส อยู่ใน Tab คลิกเลือก สะสมค้างได้ มีสัญญาณ ตายแล้วคงเดิม (14, 15, 17, 24)
- อาวุธสเตตัสต่างกัน ค่ารวมเท่ากัน (16)
- ตัวเลขดาเมจแยกสี: ธรรมดา / คริ / โจมตีหนัก คริ+หนักใช้สีคริ (30)

## อาหารและกระเป๋า
- Tab = กระเป๋า 8 ช่อง คีย์ลัด 1-4 ล่างจอ ดึงจากกระเป๋าได้ (4, 20, 21)
- อาหารเก็บเข้ากระเป๋า แสดงไอคอนแบบดาบ ใช้ผ่านคีย์ลัดหรือ Tab + คลิก กิน 1.5 วิ มี animation + แถบเวลา โดนตี/เดินยกเลิก (2, 5, 6, 7, 18)

## UI / กล้อง
- M = แผนที่ (ปรับเสียงจาก Esc เท่านั้น) Esc = เมนู Exit / Sound scroll = ปรับความสูงกล้อง (9, 10, 19)

## ยังเปิด
- ปุ่ม 1-4 ชนกับเลือกการ์ด/ใส่ดาบเดิม, ดาบเข้ากระเป๋าไหม, ช่วงมุมกล้อง
- charge ปล่อยแล้วเกิดอะไร, หน่วง 0.5 วิ (ข้อ 8) ใช้กับ charge/ท่าใหม่ไหม, อัลติ R ของ Knight (designer เสนอ)
- พีทยังไม่ได้เลือกว่าข้อไหนจะทำ และสั่งว่ายังไม่ทำทั้งอาทิตย์นี้

## อัปเดต 2026-10-11 — core ใหม่ + ลำดับความสำคัญ (ปูส้มประเมิน รอพีทปรับ)
