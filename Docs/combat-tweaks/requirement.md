## รายการที่ขอ (พีทจะเลือกว่าอันไหนทำ)
1. สกิล auto — สกิลที่ใช้เองตามเงื่อนไข
   - พีท: "อาจจะเอาสกิลที่กดทั้งหมดออก" = สกิลที่ผู้เล่นกดใช้เองจะถูกเอาออก เหลือแต่สกิลที่ทำงานเองตามเงื่อนไข (ยังเป็น "อาจจะ" ไม่ใช่ข้อสรุป)
   - เปิดอยู่: เงื่อนไขที่ใช้ (เช่น HP ต่ำ, ศัตรูล้อม, สกิลพร้อมใช้) ยังไม่ระบุ
2. Heal ยากขึ้น
   - ของ drop มาแล้ว ต้องใช้เวลา 1.5 วิ ถึง heal สำเร็จ
   - ถ้าโดนตีหรือเดินระหว่างรอ → ยกเลิก heal
   - มีแถบแสดงเวลาระหว่างรอ
3. กดคลิกซ้ายค้างเพื่อต่อ combo แทนการคลิกหลายทีได้
   - ยังคงคลิกทีละครั้งได้เหมือนเดิม (ถือว่าเป็นค่าเริ่มต้น รอยืนยัน)

## เพิ่มจากพีท 2026-10-11 (core ใหม่)

    - เปิดอยู่: โลกที่หมดอายุถูกลบรวมของที่ตกอยู่หรือไม่ (ของหายถาวร?), ตัวนับเป็นของเซิร์ฟหรือต่อผู้เล่น, โลกที่กำลังมีคนเล่นอยู่ตอนครบ 3 วัน
