## ยืนยันจากพีท 2026-10-11 (core ใหม่ ข้อ 32-38)
- ของตกตอนตาย = ของที่เอาเข้าโลกมา: อาวุธ อาหาร และของที่เก็บมาได้ในโลกนั้น (ทั้งหมด)
- กลับฐานไม่ได้จนกว่าจะฆ่าบอสโลก (ไม่มี extract กลางทาง)
- "เคยตาย" นับตามทุกคนในเซิร์ฟ; โลกที่มีคนตายถูกเก็บไว้ให้สุ่มเจออีก (กลายเป็นโลกเก่า)
- เนื้อเรื่อง (plot): ผู้กล้าช่วยโลก
- เปิดอยู่: ของที่ตกอยู่ในโลกนั้นให้ไปเก็บคืนได้ไหม (ถ้ามีโลกเก่า ให้ผู้เล่นรอบถัดไปเก็บได้ไหม), ชนกับข้อ 14/37 เรื่องอะไรถาวร
- ยืนยัน (พีท 2026-10-11): ของที่ตกในโลกเก่า ผู้เล่นรอบถัดไปที่สุ่มเจอโลกนั้นเก็บคืนได้

## ตัดสินจากพีท 2026-10-11 (core ใหม่)
- "รีเซ็ตหมด": ทุกครั้งที่เข้าโลก เลเวล สเตตัส/การ์ด และอัปเกรดสกิล (ข้อ 14) เริ่มใหม่ → ข้อ 14 ส่วน "ตายแล้วสกิลคงเดิม" ถูกยกเลิก ชนข้อ 37 ถือตามข้อ 37
- การเก็บโลกเก่า (seed/ของที่ตก/ผู้ตาย): ให้หาวิธีเก็บ (architect เสนอ) 
- co-op: เก็บข้อมูลโลกไว้ที่ host
- ตีความของปูส้ม (รอยืนยัน): "รีเซ็ตหมด" = เลเวล/สเตตัส/การ์ด/อัปเกรดสกิล/Soul; อาวุธ+อาหารที่ผู้เล่นพากลับฐานได้ยังอยู่ (เพราะข้อ 36 "รอดได้อาวุธกลับมา")

## เพิ่มจากพีท 2026-10-11 (core ใหม่)
39. โลกหมดอายุ: กัน Player ตายเยอะเกิน โลกที่เก็บไว้ (โลกเก่า) หมดอายุเป็นเวลา 3 วัน
    - จำนวน "วัน" นับตามการกลับมาจากโลก ไม่ว่าจะตายหรือรอด (1 การกลับมา = 1 วัน)
    - ตีความของปูส้ม (รอยืนยัน): ตัวนับวันเป็นของทั้งเซิร์ฟ (host) ทุกครั้งที่ผู้เล่นคนใดกลับจากโลกใดก็ +1 วัน โลกเก่านับอายุจากวันที่ถูกเก็บ ครบ 3 วัน = ถูกลบ
    - เปิดอยู่: โลกที่หมดอายุถูกลบรวมของที่ตกอยู่หรือไม่ (ของหายถาวร?), ตัวนับเป็นของเซิร์ฟหรือต่อผู้เล่น, โลกที่กำลังมีคนเล่นอยู่ตอนครบ 3 วัน

## ยืนยันจากพีท 2026-10-11 (ข้อ 39 แก้ไข)
- นับเป็น "จำนวนครั้ง" ที่ผู้เล่นกลับจากโลก ไม่ใช่วัน (หมดอายุเมื่อครบ 3 ครั้ง นับจากตอนที่โลกถูกเก็บ)
- โลกหมดอายุ = ถูกลบ ของที่ตกอยู่ในโลกนั้นหายถาวร
- ตัวนับเป็นของทั้งเซิร์ฟ เก็บที่ host (ตามข้อ co-op) — ปูส้มสมมติ พีทไม่ได้แย้ง

## เพิ่ม/แก้จากพีท 2026-10-11 (ข้อ 38)
40. ผู้เล่นเลือกได้ว่าจะเข้าโลกเก่าหรือโลกใหม่ (แทนที่ข้อ 38 ที่เดิมสุ่มเก่า/ใหม่; biome ยังสุ่ม)
    - เปิดอยู่: เลือกแค่ "เก่า/ใหม่" แล้วระบบสุ่มโลกเก่าให้ หรือเลือกโลกเก่าเจาะจงจากรายการได้ (เห็นอะไรบ้าง เช่น biome, จำนวนครั้งที่เหลือก่อนหมดอายุ, ของที่ตกอยู่), ถ้าไม่มีโลกเก่าเก็บอยู่ให้ทำอย่างไร

## ยืนยันจาก test_disk 2026-10-11 (ข้อ 19-21)
