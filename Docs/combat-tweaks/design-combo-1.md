# design-combo — ท่าคอมโบใหม่ + charge (Knight ดาบโล่)
> ส่วน 1/3 ของ `design-combo.md` (ดัชนี: `design-combo.md`) · ต่อที่ `design-combo-2.md`
เสนอโดย Designer เมื่อ 2026-10-11 ตามที่พีทสั่ง "ให้ designer เสนอมา"
สถานะ: ข้อเสนอ รอพีทอนุมัติ ยังไม่ใช่ข้อสรุป (ต้นทาง: requirement.md ข้อ 3, 8, 12-13, 28, 29)

## 1. เป้าหมายผู้เล่น
- ฟันได้หลากหลายขึ้นตามจังหวะที่ผู้เล่นเลือกเอง: พุ่งเข้าไป เดินบุก ขยับข้าง ถอยตั้งหลัก
- คลิกซ้ายอย่างเดียวยังเล่นได้เหมือนเดิม (ท่าใหม่เป็นของเสริม ไม่ใช่ข้อบังคับ)
- ค้างคลิกซ้าย = ลงทุนเวลา 1 วิ แลกกับการโจมตีหนักที่แรงและทำมอนหยุด

## 2. ข้อสมมติ (ข้อมูลไม่พอ จึงตั้งไว้ก่อน ให้พีทแก้ได้)
- A1: "ทิศ A S W D" วัดจากทิศที่ผู้เล่นกดเดิน เทียบกับทิศที่อัศวินหัน (ตามเคอร์เซอร์) แบ่ง 4 ช่อง ช่องละ 90 องศา
  W = เดินเข้าหาเคอร์เซอร์ S = เดินถอยจากเคอร์เซอร์ A/D = เดินซ้าย/ขวาของตัวอัศวิน
  (ถ้าใช้ทิศโลกตรงๆ ท่าจะไม่ตรงกับที่ตาเห็นเมื่อเมาส์ชี้ไปทางอื่น)
- A2: "หน่วง 0.5 วิ" = เวลาขั้นต่ำจากเริ่มฟันหนึ่งท่า ถึงเริ่มฟันท่าถัดไปได้ (ท่าที่จบเร็วกว่า 0.5 วิ ถูกถ่วงให้ครบ)
- A3: ท่าใหม่ทุกท่าไม่กิน stamina (เดิม stamina ใช้กับ dash อย่างเดียว) Dash Slash จ่ายค่า dash ไปแล้วตอน dash
- A4: ตัวเลขดาเมจเทียบ Side Slash = 10 (ก่อนคูณสเตตัส/ดาบ/คริ) ใช้ค่าจาก Knight.Attacks ของจริง
- A5: คอมโบเดิมหมดเวลาเมื่อไม่คลิกต่อ 0.9 วิ หลังท่าจบ (ตามโค้ดปัจจุบัน) ใช้ค่านี้ต่อ

## 3. กฎอ่านง่าย: ท่าใหม่ "แทน" ท่าเดิมที่ตำแหน่งเดียวกันในคอมโบ
- ท่าใหม่นับเป็นคลิกที่ N เท่ากับท่าเดิมที่มันแทน แล้วคลิกถัดไปไปต่อท่าเดิมตำแหน่ง N+1 ตามปกติ
- ทิศมีผลที่ "คลิกที่ 1" และ "คลิกที่ 3" เท่านั้น (คลิกที่ 2, 4, 5 เป็นท่าเดิมเสมอ)
- ลำดับความสำคัญเมื่อเข้าเงื่อนไขหลายอย่าง: charge > Dash Slash > ท่าตามทิศ > ท่าเดิม

## 4. ตารางสรุป: กดอะไร เกิดท่าไหน

ตั้งต้น: ยืนอยู่/ไม่ได้กดทิศ = ท่าเดิมตามคลิกที่ (1 Side Slash, 2 Overhead Chop, 3 Rising Slash, 4 Spin Slash, 5 Thrust)

| เงื่อนไข | คลิกที่ 1 | คลิกที่ 2 | คลิกที่ 3 | คลิกที่ 4 | คลิกที่ 5 |
|---|---|---|---|---|---|
| ยืนนิ่ง | Side Slash | Overhead Chop | Rising Slash | Spin Slash | Thrust |
| หลัง dash (Space) ใน 0.35 วิ | **Dash Slash** (ก) | ท่าเดิม | ท่าเดิม | ท่าเดิม | ท่าเดิม |
| W (เดินหน้า) | **Advance Cleave** (ข) | ท่าเดิม | **Vault Chop** | ท่าเดิม | ท่าเดิม |
| A หรือ D (เดินข้าง) | **Sidestep Slash** | ท่าเดิม | Rising Slash (เดิม) | ท่าเดิม | ท่าเดิม |
| S (เดินถอย) | **Shield Jab** | ท่าเดิม | **Retreat Slash** | ท่าเดิม | ท่าเดิม |
| ค้างคลิกซ้ายครบ 1 วิ แล้วปล่อย | **Heavy Strike** (แทรกที่คลิกไหนก็ได้ ดูข้อ 6) | | | | |

แผนภาพตัดสินใจตอนกดคลิกซ้าย:
```
คลิกซ้าย
 |-- ค้างเกิน 0.15 วิ? --> ใช่ --> โหมด charge (ข้อ 6)
 |-- เพิ่ง dash มาไม่เกิน 0.35 วิ? --> Dash Slash
 |-- คลิกที่ 1 หรือ 3 และกดทิศอยู่? --> ท่าตามทิศ (ตารางด้านบน)
 '-- นอกนั้น --> ท่าเดิมตามคลิกที่ N
```
