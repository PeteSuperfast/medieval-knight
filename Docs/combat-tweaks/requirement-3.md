## แก้จากพีท 2026-10-11 (รอบ 4) — ปรับข้อ 12-13, 29
- charge ทำดาเมจแรงขึ้น
- โจมตีหนักต้องมีการ charge เข้าไปด้วย (ไม่ใช่แค่ตีครบคอมโบอย่างเดียวตามข้อ 12 เดิม)

## ยืนยันจากพีท 2026-10-11 (รอบ 5) — แทนการตีความรอบ 4

## ข้อกำหนดการออกแบบอาวุธ โดยพีท (เจ้าของ) 2026-10-11
31. อาวุธแต่ละอันมีสกิลคลิกขวาต่างกัน หรือท่าคลิกซ้ายต่างกัน
    - แต่ละอาวุธ "ให้ user เป็นคนออกแบบ" (ผู้ใช้/ผู้ขอเป็นคนกำหนดเนื้อหา ไม่ใช่ designer คิดเอง)
    - ผลต่อ design-combo.md: ท่าคอมโบที่ designer เสนอ (12 ท่า) เป็นของดาบโล่/Knight พื้นฐาน ไม่ใช่ท่าตายตัวของทุกอาวุธ
    - เปิดอยู่: "user" หมายถึงใคร (ผู้ขอแต่ละคน หรือผู้เล่นออกแบบในเกม?), ขอรูปแบบ/แม่แบบกรอกข้อมูลอาวุธ, ตอนนี้ดาบ 5 เล่มในเกม (Weapons.All) ใช้ท่าร่วมกันอยู่

## ยืนยันจากพีท 2026-10-11 (ข้อ 31)
- "user" = ผู้ขอแต่ละคนในห้อง เป็นคนกำหนดเนื้อหาอาวุธ
- ทำแม่แบบให้กรอกต่ออาวุธ → weapon-template.md
- ดาบ 5 เล่มที่มีอยู่ (Iron Sword, Swift Rapier, Iron Greatsword, Crimson Fang, Horned King's Blade) ต้องออกแบบใหม่ทั้งหมด

## เปลี่ยน core เกมใหม่ โดยพีท (เจ้าของ) 2026-10-11
สถานะ: ใหญ่มาก (เปลี่ยนโครงเกม) เป็น requirement แยกจาก combat-tweaks ควรแยกโฟลเดอร์/feature ภายหลัง รอพีทสั่ง
32. เข้า "โลก" ใหม่ทุกครั้ง: โลกมี biome สุ่ม
33. มีบอสตาม biome และมี "บอสโลก"
34. บอสโลกตาย → กลับไปยังฐานได้
35. ผู้เล่นตาย → ของตก (ที่ตกคืออะไร ยังไม่ระบุ)
36. ผู้เล่นรอด → ได้อาวุธกลับมา (ฐาน)
37. ทุกครั้งที่เข้าโลก เริ่มเลเวลและสเตตัส/การ์ดใหม่
38. ระบบความยากของโลก: โลกที่เข้าไปสุ่ม "เก่า / ใหม่"
    - โลกเก่า = โลกที่ผู้เล่นเคยตายไปแล้ว → monster/boss เก่งขึ้นเป็นอย่างมาก

### จุดชนกับรายการเดิม (รอยืนยัน)
- ข้อ 14 "ตายแล้วสกิลอัปเกรดคงเดิม" ชนกับข้อ 37 "เข้าโลกเริ่มใหม่ทุกครั้ง" ต้องตัดสินว่าอะไรถาวร (ข้างฐาน) อะไรรีเซ็ตต่อรอบ
- แมพ 380x380 ม. คงที่ + เมือง (big-map-update) ชนกับ biome สุ่ม → ต้องมีตัวสร้างโลก (seed) ใหม่ และเมืองเดิมกลายเป็น "ฐาน"
- Soul (ยังไม่มีที่ใช้) อาจเป็นตัวเก็บความก้าวหน้าถาวร ต้องตัดสิน
- เปิดอยู่: ของตก = อะไร, "รอด" = ฆ่าบอสโลกหรือกลับฐานได้ทุกเมื่อ, "เคยตาย" = ใคร (ตัวเอง/ทุกคน) และโลกต้องถูกเก็บ (seed) ไหม, ออนไลน์ co-op ใช้โลกร่วมกันอย่างไร
