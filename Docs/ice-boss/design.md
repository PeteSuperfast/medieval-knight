# design: บอสจอมมารน้ำแข็ง Kryos (ไฟล์ 1/2: ภาพรวม ตัวเลข ห้อง HUD co-op) — ท่า/รูปลักษณ์/anim/VFX/เสียง อยู่ `design-moves.md`
อ้างอิง: requirement.md, Boss Design Doc (spec หลัก), style.md, controls/progression/weapons-and-tab/loop/online-coop, snow-map-models/tech.md (รัง = ลานหน้าประตูปราสาท)
ข้อความในเกมเป็นอังกฤษ | โค้ดล้วน ไม่มี ScriptableObject/NavMeshAgent/Animator/decal Unity (ทางเทียบเท่าอยู่ข้อ 9)

## 1. เป้าหมายผู้เล่น
อ่าน telegraph จากมุม top-down 56° แล้วหลบ (กลิ้ง Space อมตะ 0.5 วิ / ยกโล่ / parry) ใช้เวลา 4-6 นาทีต่อรอบ บอสชนะด้วยการวางแผน ไม่ใช่พลังดิบ
ใน co-op (≤4) ต้องไม่แยกตัว ช่วยคนโดนแช่ (ตี/ชุบ F 60 วิ) เล่นคนเดียวต้องชนะได้ด้วยฝีมือหลบ (ท่าไม้ตายมีทางรอดแบบเดี่ยว)
บอสแทน Minotaur เฉพาะโลกหิมะ (โลกทุ่งยังเป็น Minotaur) ฆ่าแล้ว portal เกิดเหมือนเดิม

## 2. หน้าจอ/องค์ประกอบ
1 ห้องบอส (ลานหน้าประตูปราสาท + วงกำแพงน้ำแข็ง) | 2 HUD แถบ HP บอส + poise + ไอคอนเฟส | 3 คำเตือนไม้ตาย + แถบ mash ของเหยื่อ | 4 ไอคอน Chill/Frozen ที่ตัวผู้เล่น+HUD | 5 ฉากเปิดตัว/เปลี่ยนเฟส/ตาย (banner) | 6 Ice Golem + แถบ HP เล็ก | 7 telegraph บนพื้น (ข้อ 8 ของ design-moves)

## 3. ห้องบอส (เข้ากับปราสาท) — ศูนย์ C = `MapLayout.Lair` (bake เลือกลานโล่ง r ≥ 22 ม.)
ลานวงกลมรัศมี R = 24 ม. (กว้าง ~48 ม. ≈ 2 จอที่ 56°) ถ้า bake ได้ r < 24 ให้ย่อทุกระยะตามสัดส่วน R/24 (ไม่ต่ำกว่า 22)
```
        N (ด้านบนจอ = ทางเข้าปราสาท)
         ___ ประตูปราสาท ___
        /   [T] บัลลังก์(0,+21) \      T = จุดเปิดตัว
      /   P4(-17,+17)   P1(+17,+17) \  P = จุดเทเลพอร์ตมุม r=24*0.7
     |        ( ) เสา(0,+12)         |
     | ( )เสา(-12,0)  P0 C  ( )เสา(+12,0) |  P0 = กลางห้อง
     |        ( ) เสา(0,-12)         |
      \   P3(-17,-17)   P2(+17,-17) /
        \__ ทางเข้าผู้เล่น (ใต้/ตะวันตกเฉียงใต้) __/  วงกำแพง r=26
```
- เสาน้ำแข็ง 4 ต้น (วงกลมชน r 1.4 ม. สูง 4 ม. #8FD0E4 ฐาน #6E6A78) ทั้งผู้เล่น/กระสุนบอส; ถูกทำลายโดย Absolute Zero (เฟส 3 ครั้งแรก)
- จุดเทเลพอร์ต 5 จุด: วงเวทย์บนพื้น r 2 ม. สีอ่อน #6FB8D6 ติดตลอด สว่าง #5FD8F0 ตอนบอสจะไปที่นั่น
- กำแพงปิดทางเข้า: เมื่อบอสตื่น (ผู้เล่นเข้า ≤ 16 ม. จากบัลลังก์) ผลึกน้ำแข็ง 8 ส่วนผุดเป็นวง r=26 (คอลลิเดอร์ผู้เล่น) เปิด/ละลายเมื่อบอสตาย หรือ wipe/ABANDONED; ออกกลางรอบ = Esc ตามกฎ loop เดิม
- พื้นลาน: ใช้พื้นของ bake; telegraph สีฟ้าต้องตัดกับหิมะ → telegraph ใช้ขอบเข้ม #1B2A4E บางๆ + ไส้ฟ้า (ข้อ 8)
- บอสเกิด/leash: อยู่ในวงกำแพงตลอด (ไม่มี ResetToLair กลางสู้)

## 4. ตัวเลขหลัก (ใช้กับเกมปัจจุบัน)
**ข้อมูลเกม**: ดาเมจผู้เล่น = 14 x ท่า(1.0/0.9/1.2) x ดาบ; รอบฟัน 3 ท่าต่อเนื่อง ≈ 1.5 วิ; ผู้เล่น HP = 100 + 10/เลเวล + 20/แต้ม HP (เลเวล 10 ไม่ลงแต้ม = 190); `CoopHpPerPlayer` = 0.6 (ตรงกับสูตร doc)
| ดาบ | DPS ทฤษฎี (ตีไม่หยุด, รวมคริเฉลี่ย) | DPS จริงที่บอส (uptime ~55%) |
| --- | --- | --- |
| Iron / Banana | ~30 | ~17 |
| Swift Rapier | ~29 | ~16 |
| Iron Greatsword | ~38 | ~21 |
| Crimson Fang | ~40 | ~22 |
| Horned King's Blade | ~55 | ~30 |
**เสนอ `DPS_ref = 20`** (ค่าคงที่เดียว ไม่ผูกกับดาบที่ถือ: ดาบแรงกว่าจบเร็วกว่า = รางวัล) → `HP_boss = 20 x 300 x (1 + 0.6 x (N-1)) x worldHpMul`
| ผู้เล่น | HP บอส | Golem (8%) | เวลาสู้ที่ DPS จริง (Iron 17 / Horned 30 ต่อคน) |
| --- | --- | --- | --- |
| 1 | 6,000 | 480 | 5.9 นาที / 3.3 นาที |
| 2 | 9,600 | 768 | 4.7 / 2.7 |
| 3 | 13,200 | 1,056 | 4.3 / 2.4 |
| 4 | 16,800 | 1,344 | 4.1 / 2.3 (ยังไม่หักเวลาช่วยเพื่อน/หลบ ซึ่งยืดอีก ~30%) |
- ห้ามใช้ `EnemyHpScale` (ตามเลเวล) กับบอส: ผู้เล่นไม่มีอัปเกรดดาเมจจึงไม่ควรโตตามเลเวล; ห้ามใช้ `EnemyDamageScale` เพราะดาเมจเป็น % HP ผู้เล่นซึ่งโตตามเลเวลอยู่แล้ว; โลกเก่า HP x1.5 ดาเมจ x1.25 ใช้ได้ตามเดิม
- เกราะบอส = 0 (ให้สูตร DPS ตรง ไม่ใช้ armor เหมือน Minotaur) | ความเร็ว 70% ของเดินผู้เล่น (ไม่คูณ Chill) | รัศมีตัว 1.2 ม. ผู้เล่นเดินทะลุไม่ได้
- **ดาเมจ** = % x MaxHp ของเหยื่อ แล้วเข้าท่อเดิม (โล่ > RESISTANCE > armor; กลิ้งอมตะ = ไม่โดน): กระสุน/ท่าฟาด **บล็อกด้วยโล่ได้** (ไม่ติด Chill ถ้าบล็อก); **ท่าพื้นที่** (Nova, Ice Wall, Absolute Zero, วงตัดสิน) โล่ไม่ช่วย ต้องกลิ้ง/ออกนอกวง; ท่าฟาดที่ระบุ "เบา" parry ได้ (ข้อ 5), ท่าหนัก (ขอบแดง #C8483A + `!`) parry ไม่ได้ตามกติกา phase 7; clash ใช้กับบอสไม่ได้
- **Poise/Stagger** (แทน "8% HP ใน 4 วิ" ที่ solo ทำไม่ได้): เกจสะสมดาเมจในหน้าต่าง 4 วิ เต็ม = `DPS_ref x 4 x 1.6 x (1+0.6(N-1))` = 128/205/282/358 (≈2.1% HP) ; parry ท่าเบา +40% ของเกจ; เต็มตอนบอส telegraph = ยกเลิกท่า + ชะงัก 2 วิ (ดาเมจใส่บอส x1.25), เต็มตอนพัก = ชะงัก 2 วิ; หลังชะงัก เกจล็อก 8 วิ; ไม่ชะงักตอนตัดสิน (ข้อ 5.5), เปลี่ยนเฟส, เทเลพอร์ต
- ช่วงพักระหว่างท่า 1.5 → 1.0 → 0.7 วิ | เปลี่ยนเฟสอมตะ 3 วิ ผลึกลอยแตก 1 ชิ้น ล้าง Chill ทุกคน

## 5. Flow การใช้งาน
1. ผู้เล่นเดินเข้าลาน → ผู้เล่นทุกคนค้างขยับไม่ได้ 3.5 วิ (อมตะ; ไม่หยุดเกม) บอสลุกจากบัลลังก์ ผลึก 3 ชิ้นหมุน กำแพงวงผุด HUD บอสเลื่อนลง "KRYOS - FROST LORD"
2. เฟส 1 (100-60%) → 60% เฟส 2 → 25% เฟส 3 (ธรรมเนียม: บอสอมตะ 3 วิ เล่นท่าเปลี่ยนเฟส, banner "PHASE 2/3")
3. ลูป AI: เลือกท่า → หมุนหาเป้า (ล็อกทิศเมื่อ telegraph เริ่ม) → telegraph → ปล่อย → พัก; ผู้เล่นขัดได้ตอน telegraph ด้วย poise
4. ผู้เล่นโดน Chill ซ้อน 3 ชั้น → Frozen: กด Space/คลิกซ้าย/J รัว (-0.15 วิ ต่อครั้ง) เพื่อนตีก้อนน้ำแข็งช่วยได้
5. ผู้เล่นล้ม (HP 0) = Down 60 วิ ตามเกมเดิม เพื่อน ≤3 ม. ค้าง F 2 วิ ชุบ (HP 30% โล่ 3 วิ); ทุกคนล้ม = wipe → โลกเก่าหิมะ; **เฟส 3 วิญญาณตัดสินสำเร็จ = HP 0 ทันที (เล่นคนเดียว = ตาย, co-op = Down ชุบได้)**
6. บอสตาย (Death 3 วิ ร่างแตกเป็นผลึก) → วงกำแพงละลาย → ดรอป/EXP/Soul ตามโครงเดิมของ Minotaur (ข้อ 11 คำถาม) → portal เกิดที่จุดตาย → ยืน 1.5 วิ = VICTORY (ออนไลน์: นับ 15 วิ)

## 6. ปุ่มควบคุม (ไม่เพิ่มปุ่มใหม่ ไม่มีจอย — เกมนี้ไม่รองรับ gamepad)
WASD เดิน, Shift วิ่ง, เมาส์เล็ง, คลิกซ้าย/J ฟัน (วน 3 ท่า) , คลิกขวาค้าง ยกโล่/parry, **Space กลิ้งหลบ** (6 ม. ใน 0.4 วิ อมตะ 0.5 วิ คูลดาวน์ 0.8 วิ stamina 25), F ค้าง 2 วิ ชุบเพื่อน (กินอาหารถ้าไม่มีเพื่อนล้ม), Tab/M/F2 ตามเดิม
ตอนโดนแช่แข็ง: **Space / คลิกซ้าย / J = กดรัว** (กลิ้ง/ฟันปิดอยู่); กดปุ่มอื่นไม่มีผล
Stamina ฐาน 100 = กลิ้ง 4 ครั้ง ฟื้น 26/วิ: ท่าของบอสต้องไม่บังคับกลิ้งเกิน 3 ครั้งใน 4 วิ

## 7. HUD แถบ HP บอส (กลางบน ที่ 1280x720)
```
        [◆◆◆]  KRYOS - FROST LORD                  <- ชื่อ #EEF3F8 บนแถบ #0E1224, ไอคอนผลึก 3 ดวง
  [██████████████████▌│······│·····]  6,000        <- 560x18 px  y≈58 กลางจอ (ใต้ banner เดิม)
  [▬▬▬▬▬▬▬ poise ▬▬]                               <- 560x4 px  ใต้แถบ
              ▲60%       ▲25%  = ขีดเฟส
```
- กรอบ #0E1224 ขอบ #3A2A5E | ไส้ #8FD0E4 | ส่วนที่เพิ่งเสีย (ghost 0.5 วิ) #C9D8E8 | ขีดเฟส #3A2A5E | poise #F5C25A (หมดแล้วกะพริบ) | ตอนอมตะแถบเทา #6E6A78
- ไอคอนผลึก 12 px: สว่าง #5FD8F0 = ยังอยู่ / #6E6A78 = แตกแล้ว
- โชว์เมื่อผู้เล่นใกล้บอส ≤ 45 ม. หรือตื่นแล้ว (เหมือนแถบ Minotaur เดิม) ; ตอน Judgment: ชื่อเปลี่ยนเป็นข้อความกลางจอสูง "FROZEN JUDGMENT" #5FD8F0 (ตัวใหญ่ 40 px) + ขอบจอวูบ + ชื่อเหยื่อ "<name> IS MARKED" ; แถบ mash เหยื่อ 320x16 ใต้กลางจอ y≈560 ไส้ #5FD8F0 "MASH SPACE!" (ปิดเมื่อหลุด)
- ไอคอน Chill ที่ตัวผู้เล่น: เกล็ด 1-3 ชิ้น #8FD0E4 ลอยเหนือหัว (เพื่อนเห็น) + HUD ตัวเอง 3 ช่องข้างแถบ stamina ; Frozen = ก้อนคลุมตัว #BFE6F2 โปร่งกึ่ง + แถบเวลาเล็ก

## 8. ซิงก์ co-op (ระดับ design) — host รัน AI เดียว client แสดงผล; เพิ่ม `Net.Protocol` เป็น 7 (architect)
- host ส่ง: HP, เฟส, state, ท่าปัจจุบัน + id เป้า + เวลาเริ่ม telegraph + ตำแหน่ง/ทิศบอส, จำนวนผลึก, จุดเทเลพอร์ตปลายทาง, วงปลอดภัย/เส้นกำแพง (ตำแหน่ง+seed ตายตัว), เสาที่พัง, Golem (ใช้ระบบศัตรูเดิม)
- client เล่น telegraph/VFX/anim เองจากเวลา+ท่า (เหมือนกันทุกเครื่องเพราะสูตรตายตัว) ไม่มี `UnityEngine.Random` ; host ใช้ `System.Random(seed โลก)` เลือกท่า (อยู่ฝั่ง host เท่านั้น)
- ดาเมจ: host ตัดสินว่าใครอยู่ในรูปทรง ณ เวลาโดน (เผื่อ 0.1 วิ สำหรับ ping 150 ms) แล้วส่ง `KnightHit` แบบเดิม; **เครื่องเจ้าของตัดสิน กลิ้งอมตะ/parry/บล็อก** (ระบบเดิม)
- Chill/Frozen: host ถือสถานะ แจ้งเจ้าของ; **mash**: client เหยื่อนับแล้วส่งผลรวมให้ host ทุก 0.1 วิ ; ตีก้อนน้ำแข็ง: host นับ hit
- ต้องไม่หยุดเวลาออนไลน์ ฉากเปิด/เปลี่ยนเฟสใช้ "อมตะ+ค้างปุ่ม" ไม่ใช้ pause

## 9. ทางเทียบเท่าแบบโค้ดล้วน (แทนของ Unity)
ScriptableObject → ตารางค่าคงที่ใน `BossData` (struct/const ต่อท่า) | NavMeshAgent → เคลื่อนด้วย `Obstacles.Push` + เทเลพอร์ต (บอสไม่เดินไล่) | Animator → คลิกคีย์เฟรมโค้ด (ข้อ 9 design-moves) | Decal → มาตรรูปทรงเรขาคณิตแบนบนพื้น (`Fx.MakeDecal` เดิม) ขอบ+ไส้ | Animation Event → เวลา `hitAt` ในตารางท่า | ObjectPool → พูลเล็กของกระสุน/ผลึกที่สร้างไว้ล่วงหน้า | กำแพง/เสาที่ทำลายได้ → สิ่งกีดขวางแบบถอดได้ใน `Obstacles` (architect เสนอ API)

## 10. คำถามที่ยังไม่ชัด (ต้องตัดสิน)
1. `DPS_ref = 20` และ HP 6,000 ต่อ 1 คน ตกลงไหม (ปรับหลัง playtest)
2. ดรอปบอส: ใช้ชุดเดียวกับ Minotaur (Horned King's Blade 100% + Meat x2 + EXP 250 + Soul 50)? หรืออาวุธใหม่ (ไม่อยู่ในขอบเขต requirement)
3. Judgment เฟส 3 "ตายทันที" ตอนเล่นคนเดียวหมายถึงจบรอบ (ของที่พกตกเป็นโลกเก่า) — โหดแต่ตาม doc; เสนอให้ถ้ากดรัวทัน (ข้อ 5.5 design-moves) = รอด
4. ลานหน้าประตูใหญ่พอ (r ≥ 22) ไหม ต้องรอผล bake; ถ้าไม่พอย่อห้อง/ขอ artist เปิดลาน
5. เสียงพูดของบอส: เกมใช้ไฟล์ mp3 (ไม่มีเสียงสังเคราะห์/เพลง) → เสนอเสียงคำราม/chime แทนคำพูด ; เพลงบอส 3 layer ตัด (ไม่มีระบบเพลงในเกม) หรือใช้ loop เดียว — ต้องหาไฟล์เสียงจากพีท
