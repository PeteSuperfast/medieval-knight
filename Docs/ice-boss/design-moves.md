### 2.1 ท่าที่ 10 ฟาดหาง (รายละเอียด)
- **ทำไม**: ให้ผู้เล่นที่หนีไปยืนหลังบอส (จากท่า Sweep ที่หน้าบอส) ถูกลงโทษ + ทำให้หลังบอสไม่ปลอดภัยถาวร แต่ **ตอนตัดสิน แกนผลึกอยู่ด้านหลัง** จึงต้องจังหวะเข้า-ออก (ซิงก์กับ Judgment)
- **เงื่อนไขใช้**: มีผู้เล่นอยู่ในพัดหลัง (มุม > 100° จากทิศหน้าบอส) ระยะ ≤ 7 ม. เกิน 1.0 วิ ; ไม่ใช้ติดกัน 2 ครั้ง ; ไม่ใช้ตอนบอสกำลังเข้าท่า Sweep ( ตามลำดับเดียวกันได้ต่อกัน)
- **เฟส 1**: ฟาดครั้งเดียว กวาดจากด้านซ้าย→ขวา 0.35 วิ | **เฟส 2-3**: ฟาด 2 ครั้ง สวนทิศ ห่าง 0.9 วิ (ให้กลิ้งต่อได้ 1 ครั้ง) | **เฟส 3** เพิ่มหนามผลึก 3 อันตกพื้นตามแนวฟาด (กีดขวางเล็ก r 0.6 ม. 4 วิ ไม่ดาเมจ)
- **ท่าทางอ่านจากบน**: (0.0-0.2) บอสหมุนครึ่งตัว หางยกค้างด้านหลัง → หางยกตั้งขึ้นสูง ปลายใบมีดเรืองสว่าง #5FD8F0 + พัดหลังขึ้นพื้นเป็นลำดับโตขึ้น (ขอบเข้ม #1B2A4E ไส้ #6FB8D6) (0.2-0.8) หางม้วนไปด้านตรงข้ามทิศฟาด (ตัวหางโค้ง "C") → ปล่อย: กวาดเส้นสว่าง 0.35 วิ วงกว้างเต็มพัด → พักหาง 0.5 วิ ล้มลงพื้น (ช่วงตีสวนได้ รอบหาง 1.0 วิ)
- **hitbox**: ส่วนที่หางผ่านขณะกวาดเท่านั้น (แถบหมุน กว้าง 1.6 ม. ณ ปลายหาง); ผู้เล่นโดน 1 ครั้งต่อการฟาด
- **Parry**: parry สำเร็จ = หางสะท้อน บอสเสีย poise +40% (ไม่ชะงักถ้าเกจไม่เต็ม) ; ไม่มี clash

## 3. Frozen Judgment (ปรับให้เข้ากับ clash/parry/กลิ้ง) — ท่า 6 วิ ไม่ paired animation
| เวลา | เกิดอะไร | ผู้เล่นทำอะไรได้ |
| --- | --- | --- |
| 0.0-1.5 | บอสชูคทา เลือกเหยื่อ=คนไกลเพื่อนสุด (ไม่ซ้ำ; solo = ตัวเอง) วงน้ำแข็ง r 2.2 ม. ใต้เท้าเหยื่อ ตามตัวเหยื่อ 0.9 วิแรก แล้วล็อกตำแหน่ง 0.6 วิ ; เสียงเตือนเฉพาะ + HUD | **กลิ้งพ้นวง หรือกลิ้งอมตะตรงจังหวะ 1.5 วิ = ยกเลิกทั้งท่า** บอสเสียจังหวะ 1.0 วิ ; ดาเมจ/poise เต็มตอนนี้ = ยกเลิกท่า |
| 1.5 | ถ้ายังอยู่ในวง: เหยื่อกลายเป็นก้อนน้ำแข็ง (ขยับ/ฟัน/ยกโล่ไม่ได้) | เหยื่อกดรัว Space/คลิก/J |
| 1.5-2.0 | บอสหาย โผล่ด้านหลังเหยื่อ ห่าง 3 ม. หันหน้าหาเหยื่อ (แกนผลึกจึงอยู่ไกลเหยื่อ) | – |
| 2.0-3.0 | คลื่นน้ำแข็งวงขยายจากตัวบอส (r 0→14 ม.) ผู้อื่นที่โดน Frozen 2.5 วิ (ไม่ใช่เหยื่อ) ; **เล่นคนเดียวข้ามขั้นนี้** | กลิ้งอมตะผ่านคลื่น / หลบหลังเสา |
| 3.0-6.0 | บอสกำมือ แกนหลังเปิด (สว่าง+ มีลูกศรทองชี้ #F5C25A เหนือหลังบอสบนพื้น) น้ำแข็งเหยื่อหนาขึ้น บอส **super armor** (poise ไม่ทำงาน) | ทางรอด 3 ทาง ด้านล่าง |
| 6.0 | ไม่มีใครขัด → น้ำแข็งแตก เหยื่อโดน 75% (เฟส 3: HP 0) | – |
**ทางรอด (ตัวเลขใหม่ ให้ทำได้จริงกับ HP บอสที่เสนอ):**
1. **หลุดน้ำแข็ง** สะสมแต้มถึง **24**: เหยื่อกดรัว 1 ครั้ง = 1 แต้ม (**เล่นคนเดียว 1.5 แต้ม**, ≈ 16 ครั้ง/4.5 วิ ≈ 3.6 ครั้งต่อวิ) ; เพื่อนฟันโดนก้อนน้ำแข็ง 1 ครั้ง = 6 แต้ม (4 ครั้ง = หลุด ตาม doc) ; หลุด = ไม่ดาเมจ, อมตะ 1 วิ, บอสชะงัก 0.5 วิ
2. **ทีมตีแกน** (ฟันโดนแกนด้านหลังบอส ดาเมจ x2): ถ้ารวมดาเมจถึง `DPS_ref x 3.6 x (N-1)` = 72 / 144 / 216 (≈ 1% HP บอส; doc เดิม 5% HP ทำไม่ได้ใน 3 วิ) → บอสปล่อยเหยื่อ ชะงัก 3 วิ **ดาเมจ x2 ตลอดชะงัก** (ใช้ N≥2)
3. **หลบวงแรก** (ตามตาราง 0.0-1.5)
- ขัดจังหวะ: ถ้าบอสชะงักตอน 3.0-6.0 ท่าถูกขัด เหยื่ออมตะ 1 วิ ; เล่นคนเดียว ท่าทั้งหมด 6 วิ ไม่มีคลื่น
- หลังโดนท่า เหยื่อ Frozen อมตะ 4 วิ (กฎ Frozen)

## 4. สถานะ Chill / Frozen / Ice Golem
- **Chill** สูงสุด 3 ชั้น: ช้าลง 15%/ชั้น (เดิน/วิ่งเท่านั้น ไม่รวมกลิ้ง/ก้าวท่าฟัน ตามกติกา SPEED) ลด 1 ชั้นทุก 3 วิ ถ้าไม่โดนเพิ่ม ; ติดเมื่อโดนจริง (บล็อกไม่ติด) ; 3 ชั้น → Frozen ; เฟสเปลี่ยน ล้างทุกคน ; ขึ้นเป็นเกล็ด #8FD0E4 ลอยเหนือหัว
- **Frozen** 2 วิ (กดรัว -0.15 วิ) ขยับ/ฟัน/ยกโล่/กลิ้งไม่ได้ ; ดาเมจที่รับ -30% ; หลุดแล้วอมตะต่อ Frozen 4 วิ ; ก้อนน้ำแข็ง #BFE6F2 โปร่ง ; คลื่นตัดสิน Frozen 2.5 วิ ; การ์ดรับ "ต้องไม่ทุกคน Frozen พร้อมกันโดยไม่มีทางหลบ" (คลื่นและ Frozen ติดกันห่าง ≥ 4 วิ)
- **Ice Golem**: HP 8% บอส | เดิน 60% ผู้เล่น | ท่าทุบพื้นวง r 2.5 ม. telegraph 1.0 ดาเมจ 20% (หนัก ปัดไม่ได้ บล็อกได้) | AI: ยืนเส้นระหว่างผู้เล่นที่ใกล้ที่สุดกับบอส ระยะ 3 ม. จากบอส | ตาย: แตกเป็นเศษ พื้นลื่น r 2.2 ม. 5 วิ (ผู้เล่นไถลต่อ: ความเร่งลด ไม่ใช่ Frozen) #BFE6F2/#8FD0E4 | สูงสุด 1/2/2 (เฟส 1/2/3) ; ได้ EXP 0 (ไม่ให้ฟาร์ม)
