## A. clash / parry (ยืนยันแล้วโดย test_disk 2026-10-11)
1. **Clash**: ตอนผู้เล่นฟัน ถ้าศัตรูโจมตีในจังหวะเดียวกันจากทิศตรงข้าม (ปะทะกันตรงๆ) → ทั้งสองฝั่งไม่เสียหาย และกระเด็นออกเล็กน้อย
2. **Parry**: กดคลิกขวา (บล็อก) ในจังหวะก่อนโดน ≤0.2 วิ → ไม่โดนดาเมจ ฝ่ายโจมตีกระเด็นออกเล็กน้อย; กดช้ากว่านั้น = บล็อกปกติ
3. **ท่าหนัก** (Heavy Strike ของผู้เล่น; ท่าหนักของบอสมีแสงแดง) ทะลุ clash/parry
4. ท่าเบา/หนักของศัตรูให้ designer ตัดสินว่าท่าไหนเป็น "หนัก" (มีแสงแดงเตือน)
5. ต้องมี feedback ชัด (เสียง/ประกาย/สั่นเล็กน้อย) ใช้เสียงเดิมก่อน (`Snd.Clash` มีแล้ว)
