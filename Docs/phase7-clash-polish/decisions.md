# Phase 7 — decisions (ปูส้มตัดสินคำถามของ designer; พีทแย้งได้ตอนอนุมัติ)
1. ปรับเสียงย้ายจาก M ไป **F2** (วนระดับเสียงเดิม; Esc ไม่มีเมนู sound อยู่แล้ว และห้ามเพิ่มเพราะ Esc กลางโลก = ตาย)
2. **สไลม์แดง = ท่าหนัก** (เดิมพันเลือกเป้า); สไลม์เขียว/น้ำเงิน + Minotaur Sweep = เบา; Smash/Charge = หนัก
3. พื้นเตือน Sweep เปลี่ยนแดง→ทอง (แยกเบา/หนักด้วยสี)
4. **เก็บ** กันสแปม parry 0.5 วิ (กันกดรัวได้ parry ฟรี) และโล่แฟลช 0.2 วิ (บอกหน้าต่าง parry)
5. clash = ช่วงฟาดของผู้เล่น ±0.1 วิ + ศัตรูครึ่งหน้า ±60° ≤5.5 ม. (architect ปรับตัวเลขได้ ต้องคงความหมาย)
6. แผนที่ M ไม่หยุดเกมทุกโหมด (รวม SP); วาดเฉพาะข้อมูลที่เครื่องนั้นมีอยู่แล้ว ห้ามเพิ่ม Msg เพื่อแผนที่; ห้ามแสดงศัตรู
7. จำมุมกล้องใน PlayerPrefs; ขนาดเลขหนัก 36 / คริ+หนัก 38 ตามที่เสนอ; แสดงรังบนแผนที่
8. flag "หนัก" ที่ส่งไปกับข้อความ Hit ให้ architect เลือกแบบประหยัดสุด (ถ้า bump Net.Protocol ต้องอธิบาย)
