# Phase 7 — design (ต่อ): ท่าหนักของศัตรู + flow + ปุ่ม/สี
> แยกจาก design.md §5-8 (อ่านคู่กัน)

## 5. ศัตรูท่าไหน "หนัก" (ทะลุ clash/parry)
| ศัตรู | ท่า | ระดับ | เหตุผล |
|---|---|---|---|
| สไลม์เขียว/น้ำเงิน | กระโดดทับ | เบา | ตัวเล็ก ฝูงเยอะ ให้ฝึก clash/parry |
| **สไลม์แดง** | กระโดดทับ (ดาเมจ 19) | **หนัก** | ตัวหนักสุดของฝูง มีเหตุผลให้เลือกเป้า/หลบ |
| Minotaur | Sweep (26) | เบา | ท่าที่เจอบ่อย ปัดได้ = เปิดช่อง |
| Minotaur | **Smash** (38) | **หนัก** | ตีทุบวงกลม |
| Minotaur | **Charge** (30) | **หนัก** | พุ่งทั้งเลน ปัดไม่ได้ ต้อง dash/หลบ |
| หุ่นฟาง | – | ไม่โจมตี | – |

สัญญาณเตือน (ใช้ทั้งหลักสีและรูปร่าง ไม่พึ่งสีอย่างเดียว):
- **เบา**: พื้นเตือน = ทอง #F5C25A (Sweep เปลี่ยนจากแดงเดิมเป็นทอง) ไม่มีเรือง
- **หนัก**: พื้นเตือนแดง #C8483A กะพริบ 4 Hz + ตัวศัตรู/ขวานเรืองแดง (#C8483A→#FF5A3C) + popup `!` แดง 28 ตอนเริ่มเตือน 1 ครั้ง
  - สไลม์แดง: วงแดงรัศมี 2.2→0.9 ม. หดเข้าตัวในช่วง Squash (วงหดจบ = กระโดด)
  - Smash: ขวานเรือง + วงทุบเดิมเข้มขึ้น α0.5→0.85; Charge: เขาเรือง + เลนเดิมเข้มขึ้น
- ผู้เล่น Heavy Strike: ไม่ถูก clash/ชนเสมอ (ทั้งสองฝั่งโดนดาเมจตามจริง) — ความเสี่ยงของการชาร์จ

## 6. Flow
```
ศัตรูเริ่มเตือน (สี ทอง/แดง)
 ├─ ผู้เล่นฟันตรงจังหวะ + เขาอยู่ครึ่งหน้า ── ท่าเบา ──> CLASH (ถอยคู่, ไม่เจ็บ)
 ├─ ผู้เล่นกดขวา ≤0.2 วิ ก่อนโดน ────────── ท่าเบา ──> PARRY (ศัตรูสตัน → สวน)
 ├─ ยกโล่ค้างอยู่แล้ว ───────────────────────────────> BLOCK ปกติ
 ├─ dash (อมตะ) ─────────────────────────────────────> DODGE เดิม
 └─ ท่าหนักของศัตรู (แดง) ──> clash/parry ไม่ได้ ──> บล็อก + "HEAVY" / dash / เจ็บ
```
ลำดับตัดสินเมื่อมีหลายเงื่อนไข: dash > parry > clash > block > โดน

## 7. ปุ่ม
ไม่มีปุ่มใหม่ — ใช้คลิกซ้าย/J (ฟัน), คลิกขวา (parry/บล็อก), Space (dash) เดิมทั้งหมด

## 8. สี/ขนาดสรุป
ทอง #F5C25A (clash/ท่าเบา) | ฟ้าอ่อน #CFE8FF (parry) | แดง #C8483A→#FF5A3C (ท่าหนัก) | popup 26–32 | ประกาย 12–18 อนุภาค อายุ 0.25–0.4 วิ | ออนไลน์: ประกาย/เสียง/popup เห็นทุกเครื่องเท่ากัน (ระดับเสียงตามระยะ `RemoteVolume`), กล้องสั่งเฉพาะผู้เล่นที่เกี่ยวข้อง
