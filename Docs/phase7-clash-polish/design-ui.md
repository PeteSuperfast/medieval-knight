# Phase 7 — design-ui: เลขดาเมจแยกสี / กล้อง scroll / แผนที่ M
> ข้อ 4–6 ของ requirement | ต่อสู้ clash/parry อยู่ใน `design.md`

## 1. เป้าหมายผู้เล่น
- มองเลขดาเมจก็รู้ว่าโดนคริหรือท่าหนัก; ปรับมุมกล้องตามถนัดด้วย scroll; กด M ดูว่าตัวเอง/ portal / กองของ / เพื่อน อยู่ตรงไหน โดยเกมไม่หยุด

## 2. เลขดาเมจ (ที่ลอยเหนือศัตรู — `Enemy.ShowHit`)
| ชนิด | สี | ขนาด | รูปแบบ |
|---|---|---|---|
| ธรรมดา | ขาว #FFFFFF (เดิม) | 24 | `12` |
| เกราะรับหมด (เดิม) | ฟ้าอ่อน #A6D1FF | 22 | `12` |
| **หนัก** (Heavy Strike) | **แดง #FF5040** | **36** | `40` |
| คริ (เดิม) | ส้ม #FF9E1A | 34 | `18!` |
| คริ + หนัก | **ส้มคริ** #FF9E1A | **38** | `60!` |
- ลำดับตัดสินสี: คริ > หนัก > เกราะรับหมด > ธรรมดา (หนักที่โดนเกราะยังเป็นแดง)
- เลขที่ผู้เล่นโดน (แดง `-N` / ฟ้าเกราะ) ไม่เปลี่ยน; "STUN" เหลืองเดิม
- ออนไลน์: เพื่อนตีหนัก/คริ ต้องเห็นสีเดียวกัน (ต้องมี flag "หนัก" ส่งไปกับข้อความโดนศัตรู — ให้ architect)

## 3. กล้อง (scroll)
```
เมาส์เลื่อนขึ้น = กล้องต่ำลง (เห็นไกลขึ้น)   เมาส์เลื่อนลง = กล้องสูงขึ้น (มองลงตรงขึ้น)
 40° <------------- 56° (ค่าเริ่ม) -------------> 70°
```
- 1 notch = 3° (ปรับนุ่ม ~0.15 วิ), ช่วง 40–70°, ระยะกล้อง 16 ม. คงเดิม; การเล็กด้วยเคอร์เซอร์ต้องยังตรงทุกมุม
- แสดง `Camera 52°` ที่ `hud.Notice` ~1 วิ; จำค่าไว้เครื่องตัวเอง (PlayerPrefs ไม่ลงเซฟ loop) ใช้ตอนเข้าเกมครั้งหน้า
- **ไม่ชนรายการ**: scroll มีผลเฉพาะตอน "ไม่มี panel ใดเปิด" (PREPARE, OLD WORLDS, LOOT, Tab/Carry, เลือกการ์ดเลเวลอัป, เมนู, แผนที่ M); รายการเหล่านั้นใช้ลูกศร/WASD + Enter อยู่แล้ว ล้อเมาส์ไม่ถูกใช้ — ถ้า panel เปิดอยู่ ล้อเมาส์ไม่ทำอะไร (ยังไม่เพิ่มการเลื่อนรายการด้วยล้อ)
- ที่ฐาน (ลานกลาง) ใช้ได้เหมือนในโลก

## 4. แผนที่ M
Wireframe (จอ 1280x720, panel กลางจอ 560x600):
```
+--------------------------------------------------+
| MAP                                   Sound 100% |
|  +--------------------------------------------+  |
|  | [mountain]                       [N ^]     |  |
|  |      grey                          [forest]|  |
|  | [forest]      (LAIR)                       |  |
|  |   orange        x   <- D 142 m              |  |
|  |             * PILE x2     @ Friend          |  |
|  |   [lake]    ^ YOU          [farm]          |  |
|  |   blue    [meadow]       ( PORTAL )         |  |
|  |             [TOWN: START]                   |  |
|  +--------------------------------------------+  |
|  ^ you  @ friend  x down  * loot  O portal  LAIR |
|  M / Esc = close        F2 = sound              |
+--------------------------------------------------+
```
- แผนที่สี่เหลี่ยม 520x520 px ( = 380x380 ม. ≈ 1.37 px/ม.) เหนืออยู่บน เหมือนในเกม; พื้นกรอบ #3A3A3A α0.88, ขอบ #D8CCB0
- ภูมิประเทศ: บล็อกสีแบนตามโซนใน `map-and-spawning.md` (ใช้จานสี: Meadow #8DB04A, ป่า #6C8535/#465820, ทะเลสาบ #1594BB, ภูเขา #ADABB7, เมือง #D8CCB0, ไร่ #A0B85B) ไม่มีหมอก
- **สัญลักษณ์**
| สิ่งที่แสดง | ไอคอน | สี | เงื่อนไข |
|---|---|---|---|
| ตัวเอง | สามเหลี่ยมชี้ทิศหัน 16 px | ขาว มีขอบดำ | เสมอ |
| เพื่อน (ออนไลน์) | วงกลม 12 px + ชื่อ 12 px | สีประจำผู้เล่น (ตาม TeamUi) | ยังไม่ตาย |
| เพื่อนล้ม | กากบาท | แดง #C8483A | รอชุบ |
| portal | วง 16 px | ฟ้า #1594BB | หลังบอสโลกตาย (ที่ปรากฏจริงแล้ว) |
| กองของ | เพชร 10 px + `xN` | ทอง #F5C25A | เฉพาะกองของโลกนี้ที่เครื่องนี้รู้อยู่แล้ว |
| รัง (LAIR) | ธงเล็ก + ตัวอักษร | แดงเข้ม | เท่าที่ลูกศรรังใน HUD บอกอยู่แล้ว |
| จุดเริ่ม | บ้านเล็ก | #D8CCB0 | เสมอ |
- **ห้ามแสดง**: ศัตรู/สไลม์/แพ็ค, ตำแหน่ง Minotaur ที่เลื่อน, HP/ของในกระเป๋าเพื่อน, กองของโลกอื่น, portal ก่อนเกิด — หลักการ: วาดเฉพาะของที่ฝั่งผู้เล่นเครื่องนั้นมีข้อมูลอยู่แล้ว (ไม่เพิ่มข้อความเครือข่ายใหม่เพื่อแผนที่)

### Flow
1. กด M → panel เปิด (เกมไม่หยุด ทุกโหมด: ออนไลน์/โลกจริง/SP) ผู้เล่นเดิน/สู้ได้ต่อ (panel ไม่รับคลิก); ตำแหน่งอัปเดตทุกเฟรม
2. กด M อีกครั้ง หรือ Esc = ปิด (Esc ตอนแผนที่เปิด ปิดแผนที่ก่อน ไม่นับเป็น "Esc ออกโลก = ตาย")
3. ที่ฐาน (ไม่มีโลก) กด M = ไม่เปิด; ตอน panel อื่นเปิดอยู่ (PREPARE/LOOT/Tab) M ไม่ทำอะไร
4. ปรับเสียง: **F2** วนระดับ 100% > 60% > 30% > ปิด เหมือน M เดิม (Esc เมนูไม่มี sound อยู่แล้ว และกฎ Esc กลางโลก = ตาย ห้ามเพิ่ม) แสดง `Sound: 60%` ที่ Notice เดิม + แสดงมุม panel แผนที่ + เพิ่มบรรทัดใน F1 controls

## 5. ปุ่มที่เปลี่ยน/เพิ่ม
| ปุ่ม | ทำอะไร |
|---|---|
| Scroll ล้อเมาส์ | ปรับมุมกล้อง 40–70° |
| M | เปิด/ปิดแผนที่ (เดิม = ปรับเสียง) |
| F2 (ใหม่ผ่าน `InputX.Map()`) | วนระดับเสียง |
| Esc | ปิดแผนที่ก่อน (ลำดับเดียวกับ Tab) |
จอยไม่มีในเกมนี้

## 6. ต่างจาก requirement / คำถามให้ปูส้มตัดสิน
1. **Esc ไม่มีเมนู sound อยู่แล้ว** (requirement ถามให้เช็ค) จึงเสนอ F2 — ตกลงไหม หรือจะให้เป็นปุ่มอื่น (เช่น `-` / `=`)
2. แผนที่ไม่หยุดเกมทุกโหมดรวม SP (requirement พูดถึงเฉพาะออนไลน์/โลกจริง) — เลือกแบบเดียวกันหมดเพื่อง่าย/ไม่ต้องสองกติกา ถ้าอยากให้ SP หยุดแจ้งได้
3. จำมุมกล้องด้วย PlayerPrefs ในเครื่อง (ไม่ใช่ไฟล์เซฟ loop ไม่ชนเซฟ) — ตกลงไหม
4. เลขหนัก/คริ+หนักใส่ขนาดใหญ่ขึ้น (36/38) นอกเหนือจาก "แยกสี" — ถ้าอยากคงขนาดเดิมแจ้งได้
5. เสนอแสดงรัง (LAIR) บนแผนที่ เพราะ HUD บอกทิศ/ระยะอยู่แล้ว ไม่ได้เผยข้อมูลเพิ่ม — ถ้าไม่เอาตัดได้
6. แผนที่ไม่ใช่ fog-of-war (เห็นภูมิประเทศทั้งหมด) เพราะแมพคงที่/ผู้เล่นรู้อยู่แล้ว — ถ้าโลกสุ่มต่างกันต่อ seed ให้ architect ยืนยันว่าบล็อกโซนอ่านจากข้อมูลโลกนั้นจริง
