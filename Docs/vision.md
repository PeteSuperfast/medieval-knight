# Vision — medieval-knight (v2: core ใหม่)
> core loop นี้พีทเป็นคนกำหนด (2026-10-12) — ปูส้มใช้ไฟล์นี้เป็นกรอบตัดสินทุกงาน
> หัวข้อ "รอพีทตัดสิน" ต้องตอบก่อนเริ่ม phase ที่เกี่ยวข้อง

## เกมนี้คืออะไร
Action RPG มุมมองบน ผู้กล้าออกจากฐานไปช่วยโลกที่ถูกยึด เข้าโลกสุ่ม เริ่มจากศูนย์ทุกครั้ง
ต้องโค่นบอสโลกถึงจะกลับได้ — รอดได้อาวุธ ตายเสียของทั้งหมดไว้ในโลกนั้น
เล่นคนเดียวหรือ co-op สูงสุด 4 คน

## Core loop
```
ฐาน → เลือกโลก (ใหม่/เก่า) → สู้ (เลเวล 1 ใหม่) → บอส biome → บอสโลก → กลับฐาน
```
1. **ฐาน** — เตรียมอาวุธ/อาหาร เลือก "โลกใหม่" (biome สุ่ม) หรือ "โลกเก่า"
2. **ในโลก** — เลเวล/สเตตัส/การ์ดเริ่มใหม่ทุกครั้ง สู้มอนได้ EXP ดรอปอาวุธ (เกรด Rust → God) และอาหาร มีบอสประจำ biome (ไม่บังคับ — ไม่ต้องฆ่าก่อนเจอบอสโลก)
3. **บอสโลก** — คนละตัวกับบอส biome, ฆ่าได้ถึงกลับฐาน กลับก่อนไม่ได้
4. **ผลลัพธ์**
   - รอด → อาวุธที่ถืออยู่กลับฐานด้วย
   - ตาย → ของทั้งหมดที่ถืออยู่ตกในโลกนั้น ทั้งของที่เอามาจากฐานและของที่เก็บได้ในรอบนั้น
     โลกนั้นกลายเป็น "โลกเก่า" ยากกว่าเดิม ใครเข้าไปเก็บคืนได้
5. **ตัวกัน/ตัวดัน**
   - โลกเก่ายากกว่ามาก: เสี่ยงสูง แต่ได้ของที่ตกคืน
   - โลกเก่าหมดอายุเมื่อมีการกลับฐานสำเร็จครบ 3 ครั้ง → ของในโลกนั้นหายถาวร

## คำศัพท์
- ใช้คำว่า **"อาวุธ"** เสมอ ไม่ใช้ "ดาบ" เป็นคำเรียกรวม — เกมจะมีอาวุธหลายประเภท
- ใช้ "ดาบ" ได้เฉพาะตอนพูดถึงอาวุธประเภทดาบจริงๆ ชิ้นใดชิ้นหนึ่ง
- ชื่อในโค้ดใหม่ใช้ Weapon ไม่ใช้ Sword (ของเดิมที่ชื่อ Sword ค่อยๆ เปลี่ยนเมื่อแก้ไฟล์นั้น ไม่ต้องรื้อทีเดียว)

## เสาหลัก (ฟีเจอร์ใหม่ต้องเสริมอย่างน้อย 1 ข้อ)
1. **ต่อสู้รู้สึกดี** — คอมโบ dash ยกโล่ อ่านท่าบอสได้
2. **เดิมพันจริง** — ของที่พกเข้าไปมีค่า ตายแล้วเจ็บ แต่มีทางกู้คืน
3. **ทุกรอบไม่ซ้ำ** — biome สุ่ม อาวุธสุ่มเกรด การ์ดสุ่ม
4. **ไปด้วยกันดีกว่า** — co-op ช่วยกันรอด (knock down + revive)

## Co-op
- สูงสุด 4 คน, ล้ม (knock down) แล้วเพื่อนกด F ชุบได้
- ข้อมูลโลก (ใหม่/เก่า/ของที่ตก/อายุ) เก็บที่เครื่อง host

## เนื้อเรื่อง
ผู้กล้าช่วยโลก — **เป็นแค่กรอบ**: ข้อความเปิดเกม ชื่อโลก/บอส คำบรรยายสั้นๆ ไม่มีบทสนทนา ไม่มี cutscene

## ไม่ทำ (ห้ามข้ามจนกว่าพีทแก้ไฟล์นี้)
- ไม่มีบทสนทนา/เควสต์/NPC คุยยาว
- ไม่มีอาวุธยิงไกลของผู้เล่น (ถ้าจะมีในอนาคต ต้องแก้ vision ก่อน)
- ไม่มี crafting ฟาร์ม สร้างฐาน (ฐานเป็นแค่ที่เตรียมตัว)
- ไม่มี class ใหม่ จนกว่าอัศวินจะครบ loop
- ไม่มีร้านค้า/เศรษฐกิจ จนกว่าจะตัดสินเรื่อง Soul
- ไม่ทำโลกใหญ่กว่า 380×380 ม. ต่อโลก
- ไม่มีเซิร์ฟเวอร์กลาง ข้อมูลอยู่ที่ host เท่านั้น
