## เป้าหมาย
เล่น loop ครบรอบด้วยกันสูงสุด 4 คน: ฐาน → เตรียมของ → เข้าโลกด้วยกัน → ล้ม/ชุบ → ฆ่าบอสโลก → กลับฐานด้วยกัน
เสร็จเมื่อ (ตาม vision): **mptest ผ่านกับ loop ใหม่**

## ที่พีทตัดสินแล้ว
1. **ล้มแล้วนับถอยหลัง 60 วิ** ไม่มีใครชุบ = ตาย (พีท 1.A); **ทุกคนล้มพร้อมกัน (wipe) = จบรอบ ทุกคนตาย** ของที่พกทั้งหมดตกในโลกนั้น → โลกเก่า โดย **ของของแต่ละคนตก ณ ตำแหน่งล่าสุดของคนนั้น** (พีท 11:38 UTC) = กองแยกตามคน ไม่รวมเป็นกองเดียว
2. **ทีมรอด (กลับฐานได้) = ไม่เกิดโลกเก่า และคนที่ตายไปแล้วไม่เสียของ** ของที่พกกลับเข้าคลังตามปกติ (พีท 2)
3. **กองของที่ตก ใครในทีมก็เก็บได้** ไม่ล็อกเจ้าของ (พีท 3.B)
4. จากเดิมใน vision: ข้อมูลโลก (ใหม่/เก่า/กอง/อายุ) เก็บที่ host เท่านั้น; ล้ม (knock down) แล้วเพื่อนกด F ชุบ; ไม่มีเซิร์ฟเวอร์กลาง
5. ของ phase 1–2 ยังเหมือนเดิม: เลเวล/EXP/การ์ด/สเตตัสเป็นของแต่ละคน เริ่ม 1 ใหม่ทุกรอบ; ตัวนับโลกเก่าลดทุกครั้งที่ทีมกลับฐาน (นับ 1 ครั้งต่อทีม ไม่ใช่ต่อคน)

## ขอบเขต (ต้องทำ)
**ห้อง / ฐาน**
- Host Game / Join Game จากเมนู เข้า loop ใหม่ (ฐาน → PREPARE ของแต่ละคน → เข้าโลก) ไม่ใช่สนาม v1 เดิม
- คลัง/ช่องพก/เซฟเป็นของแต่ละคนบนเครื่องตัวเอง; **โลกเก่าและกองของอยู่ที่ host** client เข้าโลกเก่าของ host ได้
- host เป็นคนกด "เข้าโลก" (ใหม่ หรือเลือกโลกเก่า) เมื่อทุกคนใน PREPARE กด Ready หรือ host บังคับเริ่ม
- คนเข้าห้องระหว่างทีมอยู่ในโลก → รอที่ฐานจนจบรอบ (ไม่เข้ากลางโลก)

**ล้ม / ชุบ**
- HP 0 = ล้ม (ไม่ตายทันที) มีนับถอยหลัง 60 วิ; เพื่อนอยู่ใกล้กด F ค้าง ~2 วิ ชุบได้ (กลับมา HP 30%)
- ล้มแล้วหมดเวลา = ตาย: ดูผู้เล่นอื่นต่อได้ ไม่ฟื้นกลางโลก รอทีมจบรอบ
- ทุกคนล้ม/ตายหมด = จบรอบ (wipe): ของที่พกของแต่ละคนเป็นกองของตัวเอง ณ ตำแหน่งล่าสุดของคนนั้น (ที่ล้ม/ตาย) → 1 โลกเก่ามีได้หลายกอง; ทุกกองใครก็เก็บได้

**บอสโลก / กลับฐาน**
- ฆ่า Minotaur → portal; กลับฐานแบบทีม (ดูตาราง "รอยืนยัน")
- คนที่รอดและคนที่ล้ม/ตายไปแล้ว ของที่พกกลับเข้าคลังของตัวเอง (ข้อ 2); ของที่เก็บมาเกินช่องคลัง = LEFT BEHIND เหมือน phase 1

**โลกเก่าในทีม**
- เข้าโลกเก่าได้ทั้งทีม; กองรวมของทุกคนที่ตายในครั้งนั้น เก็บคืนได้ตามช่องพกของแต่ละคน
- ตัวคูณความยากโลกเก่าคูณกับตัวคูณตามจำนวนผู้เล่นของ v1 (`CoopHpPerPlayer`)

**ออนไลน์ / ระบบ**
- ขาดการเชื่อมต่อ/ปิดเกมกลางโลก = นับเป็น ABANDONED ของคนนั้น (ของที่พกหาย — ตกเป็นกอง/ไม่กลับคลัง เหมือน phase 1–2) host หลุด = ทุกคนกลับเมนู; เซฟของ client ที่ยังไม่ได้เข้าโลก/ยังไม่ปิดรอบต้องไม่เสียหาย
- เพิ่ม `Net.Protocol` เป็นเวอร์ชันใหม่ (คนละเวอร์ชันถูกปฏิเสธเหมือนเดิม)

## ไม่ทำใน phase นี้ (อยู่นอก scope)
- biome เพิ่ม / บอส biome / เกรดอาวุธ → phase 3 (พักไว้)
- Soul (ซ่อนต่อ), ร้านค้า, แชทเสียง, matchmaking, ห้องสาธารณะ, เซิร์ฟเวอร์กลาง, ระบบกันโกง/รหัสผ่านห้อง
- เล่นข้าม internet ให้ง่ายขึ้น (ยัง LAN / port forward / VPN ตามเดิม)
- โลกเก่าส่วนตัวต่อคน (โลกเก่าเป็นของ host/ห้องเดียว ไม่ผูกกับเจ้าของของ)
