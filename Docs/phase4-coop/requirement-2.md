## เกณฑ์เสร็จ (ต้องทำให้ได้ทั้งหมด)
1. host + 2–3 client เข้าห้อง → PREPARE ของตัวเอง → host เข้าโลก → ทุกคนเกิดในโลกเดียวกัน เลเวล 1 ใหม่
2. คนหนึ่งล้ม → เพื่อนกด F ชุบได้ ภายใน 60 วิ; ไม่มีคนชุบ → ตายตามเวลา
3. ทีมฆ่าบอส กลับฐาน ทั้งที่มีคนตายไปแล้ว → ทุกคน (รวมคนตาย) ของเข้าคลังเอง ไม่มีโลกเก่าเกิด
4. ทุกคนล้ม → จบรอบ → โลกนั้นเป็นโลกเก่าบน host ของแต่ละคนอยู่ที่ตำแหน่งล่าสุดของคนนั้น (หลายกอง) → ทีมกลับเข้าไปเก็บคืนได้ ใครก็เก็บได้
5. ตัวนับโลกเก่าลด 1 ต่อการกลับฐานของทีม (ไม่ลดเป็นจำนวนคน)
6. client หลุด/ปิดเกมกลางโลก = ABANDONED เฉพาะคนนั้น ทีมที่เหลือเล่นต่อได้
7. Single Player ยังเล่น loop ได้เหมือนเดิม (selftest loop เดิมไม่พัง)
8. build ผ่าน, selftest 0 FAIL, mptest ชุดใหม่ (ล้ม/ชุบ/ทีมรอด/wipe/หลุด/โลกเก่า) FAIL=0
9. ไฟล์เอกสารแต่ละไฟล์ ≤ 10KB

## รอยืนยัน (ปูส้มเสนอค่าเริ่มต้น แก้ได้)
| หัวข้อ | ค่าที่เสนอ | เหตุผล |
|---|---|---|
| กลับฐานแบบทีม | พอมีคนที่รอดเข้า portal ครบ 1.5 วิ → นับถอยหลัง 15 วิทั้งทีม แล้วทุกคนที่ยังอยู่ในโลกกลับพร้อมกัน | ไม่ทิ้งใครไว้ข้างหลังโดยไม่ตั้งใจ; ให้เวลารวมตัว |
| ผู้เล่นที่ตายแล้วกลางรอบ | ดูเพื่อน (spectate) จนจบรอบ ไม่ฟื้น | ตรงข้อ 1 ของพีท "ตาย" และสร้างแรงจูงใจชุบ |
| ชุบแล้ว HP | 30% + โล่ 3 วิ | กันโดนซ้ำทันที |
| ระยะชุบ | ≤ 3 ม. ค้าง F 2 วิ (ถูกตีสะดุดได้) | เสี่ยงเล็กน้อยตามเสาหลัก "เดิมพันจริง" |
| เริ่มรอบ | host กด เข้าโลก (ทุกคนต้อง Ready หรือ host บังคับ) | ง่ายสุด ไม่ต้องโหวต |
| กองหลายกองต่อโลก (ผลของข้อ wipe) | กองไม่ย้ายอีก: ตกใหม่ที่ตำแหน่งไหนก็เป็นกองที่นั่น (ใกล้กองเดิม ≤ 3 ม. รวมเข้ากองนั้น); เพดานรวม 48 ชิ้นต่อโลกเท่าเดิม; **แทนกติกา phase 2 ข้อ "ตายซ้ำ กองย้ายไปจุดล่าสุด"** (decisions ข้อ 7) — Single Player ได้กติกาเดียวกัน | ตำแหน่งต่อคนทำให้ "ย้าย" ไม่มีความหมาย; ใช้กติกาเดียวทั้งเดี่ยวและทีม |
| ลูกศรชี้กอง | ชี้กองที่ใกล้สุดที่ยังมีของ | หลายกอง |
| คนที่รอดเก็บของคนอื่นจากกอง | ได้ (พีท 3.B) ของที่ถือกลับ = ของเขา | ไม่ต้องมีเจ้าของใน data |
| เมนู v1 arena (Host/Join เดิม) | ย้ายไปสวิตช์ command line (`-arena`) จน mptest ชุดเก่าย้ายครบ ไม่แสดงในเมนู | ไม่ทิ้งเครื่องมือเทสต์ แต่ผู้เล่นเห็นเฉพาะ loop |
