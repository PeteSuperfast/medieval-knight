## จาก design.md หัวข้อ 8
1. **LOOT ในทีม (เกมไม่หยุด): ให้โล่ 6 วิ ครั้งเดียวต่อการเปิดหน้าต่าง** เหมือน `LevelUpProtect` ของ v1

3. **ระหว่างนับ 15 วิกลับฐาน คนล้มยังชุบได้** ไม่ขยายเวลา

5. **OLD WORLDS แถวเดียวต่อโลก แสดง `n piles`** (รวมของทุกกอง)

## ข้อที่ design.md ตัดสินเพิ่มจาก requirement — ปูส้มรับ
- F = ชุบเมื่อมีเพื่อนล้ม ≤ 3 ม. ไม่งั้นเป็นสกิลเดิม (Ground Slam); คนล้มขยับ/โจมตีไม่ได้; ป้ายกองไม่แสดงเจ้าของ; client ดูรายการโลกเก่าของ host แบบอ่านอย่างเดียว

## ข้อให้ architect ระวัง
- ต้องเพิ่ม `Net.Protocol` (เวอร์ชันใหม่) และระบุรายการข้อความใหม่/ที่เปลี่ยนใน tech.md ชัดเจน
- ข้อมูลโลกเก่า/กองอยู่ที่ host เท่านั้น (`Net.Authority`); client เก็บคลัง/เซฟตัวเอง; Single Player ต้องไม่พัง
- กติกากองใหม่ (หลายกอง ไม่ย้าย รวมถ้า ≤ 3 ม.) แทน phase 2 decisions ข้อ 7 — ต้องแก้ OldWorld/Loadout/LoopSave (เซฟเก่า 1 กองต้องเปิดได้)
- ห้ามหยุดเวลาตอนออนไลน์ (`Game.Paused`); หน้าต่าง LOOT/Tab เป็น overlay
- แผน mptest ชุดใหม่: ล้ม/ชุบ/ทีมรอด/wipe/หลุด/โลกเก่า + ย้ายชุดเก่าของ v1 arena ไป `-arena`

## จาก tech.md / tech-net.md (ปูส้มตัดสิน 2026-10-13)
6. **คนหลุดกลางรอบแล้วทีมชนะกลับฐาน: ของคนหลุดหายถาวร ไม่เกิดโลกเก่า** (ตาม requirement ข้อ "ทีมรอด = ไม่มีโลกเก่า"); ถ้าทีม wipe → ของคนหลุดเป็นกองตามตำแหน่งที่หลุด — **ต้องแจ้งพีท** (หลุดเพราะเน็ตก็เสียของ)
7. **host ปิดเกมกลางรอบ: host สร้างกองให้ทุกคนจาก mirror** (ตำแหน่งล่าสุดของแต่ละคน) ไม่ใช่เฉพาะของ host — ไม่ให้ client เสียของเพราะ host ปิด; ถือเป็น ABANDONED ทั้งทีม
8. **โลกเก่าส่วนตัวในเซฟ client (จาก Single Player) ไม่ลดตัวนับตอนเล่นออนไลน์** (ตามที่ architect เสนอ)
9. **race เก็บของพร้อมกัน ~100 ms: ยอมรับได้** ถ้าเต็มให้ของยังอยู่ที่พื้น/กอง ไม่หาย (ขั้น 6 ต้องเลือกวิธีที่ไม่ทำให้ของหาย; ถ้าทำไม่ได้ต้องแจ้งก่อน ไม่ใช่ปล่อยเงียบ) ไม่ทำ 2-phase confirm
10. **คนรอที่ฐานไม่เห็นอัศวินเพื่อน เห็นแค่ panel** ยืนยัน
