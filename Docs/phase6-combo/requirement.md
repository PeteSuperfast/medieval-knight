## เป้าหมาย
ทำท่าคอมโบเพิ่มและการชาร์จโจมตีหนักของอัศวิน ตามที่ design-combo.md + decisions.md ตัดสินแล้ว บน loop ปัจจุบัน (Single/Host/Join)

## ต้องทำ (ตามเอกสารเดิม ไม่เปลี่ยนความหมาย)
- ท่าตาม `Docs/combat-tweaks/design-combo.md` ครบ 7 ท่า: Dash Slash, Advance Cleave, Sidestep Slash, Shield Jab, Vault Chop, Retreat Slash, Heavy Strike
- ค่าที่พีทตัดสินแล้วใน `Docs/combat-tweaks/decisions.md` (ข้อ 1–6 + ค่าแนะนำ designer ข้อ 1–12) ใช้ตามนั้น
- requirement ต้นทางที่เกี่ยวข้อง: `Docs/combat-tweaks/requirement.md` ข้อ 3, 8, 12, 13, 28, 29 (ไฟล์ใหญ่ อ่านเฉพาะข้อเหล่านี้)
- คลิกซ้ายค้าง = ชาร์จเต็ม 1 วิ = โจมตีหนัก (มอนหยุด 0.5 วิ ไม่กิน stamina ชาร์จเดินช้า 50% โดนตีไม่ยกเลิก); หน่วงฟัน 0.5 วิ ทุกคลิก

## ข้อกำหนดเพิ่ม (ปูส้มใส่ เพราะโค้ดเปลี่ยนไปจาก design เดิม)
1. ออนไลน์: ท่าใหม่/ชาร์จต้องเห็นตรงกันทุกเครื่อง (`Game.Coop`, `Net.Authority`) — ถ้าเพิ่มข้อความเครือข่ายต้องเพิ่ม `Net.Protocol` (ตอนนี้ 3) และ mptest ทั้ง 2 ชุดผ่าน
2. ทำงานร่วมกับล้ม/ชุบ (Down/Fallen), โล่ชุบ, Ground Slam F (กฎ F เดิมของ phase 4 ไม่เปลี่ยน)
3. ไม่แตะ loop/โลกเก่า/เซฟ; ไม่เพิ่มปุ่มที่ชนปุ่มเดิม (ถ้าต้องเพิ่มต้องผ่าน `InputX.Map()`)
4. อาวุธทั้ง 6 เล่มใช้ท่าชุดเดียวกันไปก่อน (ท่าเฉพาะอาวุธอยู่ phase 3/พักไว้)

## ไม่ทำ
clash/parry (ข้อ 41–42), สกิลตามอาวุธ/อัลติ R, อัปเกรดสกิล, กระเป๋า 8 ช่อง, ตัวเลขดาเมจแยกสี, อาวุธใหม่, class ใหม่ → backlog

## เกณฑ์เสร็จ
build ผ่าน, selftest 0 FAIL (เพิ่มเคสท่าใหม่/ชาร์จ), mptest.ps1 (`-arena`) + mptest-loop.ps1 FAIL=0, -menutest ผ่าน, เอกสารแต่ละไฟล์ ≤10KB, พีทลองเล่นแล้วรู้สึกดี
