## 4. Flow
1. ตายโลกใหม่ → G YOU FELL + บล็อก CREATED → RETURN TO BASE → C2 (OLD WORLDS (1))
2. C จัด carry (เว้นช่องว่างไว้รับของ) → OLD WORLDS → H เลือกแถว → ENTER OLD WORLD → เซฟ → fade 0.5 วิ
3. เกิดในโลก แบนเนอร์ 4 วิ `OLD WORLD #A3F2` / `Your loot lies where you fell. 142 m away.` ลูกศรทองชี้ตั้งแต่เริ่ม
4. เดินถึงกอง → L เปิด → คลิก/Enter ที่ชิ้นเพื่อเก็บเข้าช่องตามกฎเดิม (Weapon รวม +N ตามกฎ phase 1) หรือ Take all (เก็บเท่าที่ใส่ได้) → Esc/Tab ปิด
   - เต็ม: ช่องสั่นแดง + `Pack full! Can't take <name>` ของยังอยู่ในกอง; กองหมด = ควัน + `Everything recovered.`
   - ปิดแล้วต้องเดินออกพ้น ~4 ม. ก่อนจะเปิดอีก (กันเด้งซ้ำ)
5. ฆ่า Minotaur (ตัวใหม่ ยากขึ้น) → portal + flow เดิม → G VICTORY + บล็อก OLD WORLDS (ตัวนับทุกโลกลด 1; ถึง 0 = CRUMBLED)
6. RETURN TO BASE → C2 (แถบแดงแจ้งสลาย ถ้ามี) ของที่เก็บมาอยู่ใน stash
7. ตายอีกในโลกเก่า → G ตามข้างบน ของที่พกรวมเข้ากองเดิม
8. ปิดเกมกลางโลกเก่า = ABANDONED เหมือน phase 1 → ของที่พกเข้ากอง (ถือเป็นตายในโลกเก่านั้น)

- ธีมโลกเก่า = ม่วงเทา #5E5878 (กรอบแถวที่เลือกยังทอง #D9A441); ของที่ตก/กอง = ทอง #F5C25A; เตือน/เหลือ 1 = #F2C14E; สลาย/เสีย = #E05050; ได้ = #6FD16F
- ป้าย HUD D2 ขวาบน ห่างขอบ 24 px ตัวอักษร 22 px พื้นดำโปร่ง กรอบม่วงเทา (เหลือ 1 ครั้ง กรอบเหลือง)
- ลูกศรชี้กอง ~48 px สีทอง วางที่ขอบจอ (portal ใช้ลูกศรฟ้าเดิม ถ้าแสดงพร้อมกันเว้นห่างกัน)

- (เสริม ไม่บังคับ) ฟอกโลกเก่า: หมอก/แสงอมม่วงเทา #5E5878 เล็กน้อย บอกว่าอยู่โลกเก่า

## 7. ที่ต่างจาก requirement / ตัดสินเพิ่ม
1. ปุ่ม ENTER WORLD เดิมแยกเป็น NEW WORLD + OLD WORLDS (requirement ให้ "มีทางเลือก" ไม่ระบุตำแหน่ง)
2. ใช้ "ลูกศรขอบจอ + ลำแสง" ไม่ทำมินิแมพ (เกมไม่มีมินิแมพ; requirement ให้เลือกอย่างใดอย่างหนึ่ง)
3. กองต้องเดินชน → เปิดหน้าต่างเลือกเก็บ (ไม่เก็บอัตโนมัติ) เพื่อให้เลือกชิ้นดีก่อนช่องเต็ม
4. ชื่อโลก `#รหัส` จาก seed (requirement ให้เก็บเลขอ้างอิงไว้ ไม่ได้ระบุชื่อ)
5. แจ้งสลายแสดง 2 จุด: G (ตอน VICTORY) และแถบแดงใน C2 ครั้งแรกที่ฐาน

## 8. คำถามให้ปูส้มตัดสิน
1. โลกเก่าที่กองหมดแล้ว (เก็บครบ) ให้ปิดโลกทันทีไหม (ดีไซน์นี้ปิด; ถ้าไม่ปิด จะเหลือโลกว่างในรายการจนหมดอายุ)
2. กองเก็บของซ้ำชนิดเดียวกัน (Weapon เดียวกัน) แยกชิ้นหรือรวม +N ตอนตกเป็นกอง (เสนอแยกชิ้น; รวม +N เฉพาะตอนเก็บเข้าช่องตามกฎเดิม)
3. เวลาในแถว "Fell Oct 13, 14:32" ใช้นาฬิกาเครื่อง ok ไหม (หรือใช้ "N runs ago" แทน)
4. ตัวคูณความยากเหมือนกันทุกโลกเก่า (ตามตาราง) — แถวจึงแสดงตัวคูณเดียวที่หัวรายการ ไม่แยกต่อแถว
5. ตายหลังฆ่าบอสในโลกเก่าแต่ก่อนเข้า portal: บอสเกิดใหม่ครั้งหน้า (ตาม requirement) ใช่ไหม
6. ฟอกหมอกม่วงเทาในโลกเก่า: เอา/ไม่เอา (ไม่กระทบกฎ)
