## เป้าหมาย
ตายแล้วมีเหตุผลให้กลับไปเก็บของคืน: โลกที่ตายกลายเป็น "โลกเก่า" ยากกว่าเดิม มีของที่ตกรออยู่ และหมดอายุเมื่อกลับฐานสำเร็จครบ 3 ครั้ง
เสร็จเมื่อ (ตาม vision): **ตายแล้วกลับไปเก็บของคืนได้**

## ที่พีทตัดสินแล้ว
1. ตาย → ของที่พกทั้งหมด (จากฐาน + เก็บได้ในรอบ) ตกในโลกนั้น (vision, 2026-10-12)
2. **ตัวนับหมดอายุ = นับทุกครั้งที่กลับฐาน รอด ตาย หรือ ABANDONED จากโลกไหนก็ได้** (พีท "1.a"; ตาย/ABANDONED นับด้วย 2026-10-13 11:19 UTC)
3. **ระบบเลเวลข้ามรอบเดิมถูกแทนด้วยกติกาใหม่ทั้งหมด** (พีท 2026-10-13 "2.ใช่") — ใน loop: เลเวล/EXP/การ์ด/สเตตัสเริ่มใหม่ทุกรอบ เก็บข้ามรอบเฉพาะอาวุธในคลัง (phase 1 ทำไว้แล้ว)
4. บอสโลกยังเป็น Minotaur และต้องฆ่าก่อนกลับ (phase 1)
5. ข้อมูลโลกอยู่ที่ host; phase นี้เล่นคนเดียว = เครื่องผู้เล่นเอง (เซฟไฟล์เดียวกับ LoopSave)

## ขอบเขต (ต้องทำ)
**เซฟโลก**
- ตายหรือปิดเกมกลางโลก (ABANDONED) → สร้างบันทึก "โลกเก่า": ตำแหน่งที่ตาย, รายการของที่ตก, ตัวนับหมดอายุ (เหลือกลับฐานอีกกี่ครั้ง เริ่ม 3), เลขอ้างอิง seed ของโลก
- ฆ่าบอสโลกได้และรอดกลับฐาน = โลกนั้นจบ ไม่กลายเป็นโลกเก่า

**ของที่ตก**
- ของที่พกทั้งหมดรวมเป็นกองเดียว ณ จุดที่ตาย (มีป้ายบอกกลางจอ/มินิแมพหรือลูกศรชี้ตอนอยู่ในโลกเก่า)
- เก็บคืนได้ตามช่องพกเดิม (อาวุธ 2 / อาหาร 3 / สัมภาระ 4) เต็มแล้วเก็บเพิ่มไม่ได้ ของที่เหลือคงอยู่ในกอง
- ของที่เก็บคืนมา ถ้ารอด → เข้าคลัง; ถ้าตายอีก → ตกในโลกนั้นอีก (รวมเข้ากองเดียว)

**ความยาก**
- โลกเก่ายากกว่าโลกใหม่ชัดเจน: ศัตรูพลังชีวิต/ดาเมจสูงขึ้น และมีศัตรูมากขึ้น (ตัวเลขดูตารางรอยืนยัน)
- บอสโลกเป็น Minotaur เดิมแต่ยากขึ้นตามตัวคูณเดียวกัน

**หมดอายุ**
- ทุกครั้งที่กลับฐาน (รอด ตาย หรือ ABANDONED) ตัวนับของทุกโลกเก่าที่มีก่อนรอบนี้ลด 1 รวมโลกที่ตายข้างใน; โลกที่เพิ่งเกิดจากการตายครั้งนี้เริ่ม 3 เต็ม
- ถึง 0 → โลกนั้นและของในกองหายถาวร แจ้งผู้เล่นที่ฐาน (เช่น "โลกเก่า X สลายไปแล้ว")
- ตายในโลกเก่าที่เหลือ 1 → สลายพร้อมกอง (ของที่เพิ่งตกหายด้วย)

**ฐาน / เลือกโลก**
- หน้าเข้าโลกมีทางเลือก "โลกใหม่" กับ "โลกเก่า" (รายการ: ตายเมื่อไหร่/ของกี่ชิ้น/เหลือกลับฐานอีกกี่ครั้ง/ความยาก)
- ไม่มีโลกเก่า → ปุ่มโลกเก่าปิดอยู่

**เซฟไฟล์**
- LoopSave ขยายเก็บรายการโลกเก่า; ไฟล์เซฟ phase 1 เดิมต้องเปิดได้ (ไม่มีโลกเก่า = ว่าง) ไฟล์เสียต้องไม่ crash (เหมือน phase 1)

## ไม่ทำใน phase นี้ (อยู่นอก scope)
- biome เพิ่ม / บอส biome / เกรดอาวุธ Rust→God → phase 3
- co-op ของ loop: host เก็บโลกเก่า, ชุบ, ตายหลายคน → phase 4 (Host/Join ยังเป็นสนาม v1 ไม่แตะ ห้ามให้โลกเก่ารั่วเข้า)
- Soul: ยังซ่อน ไม่ผูกกับโลกเก่า (รอพีทตัดสินเรื่อง Soul)
- ลบระบบ v1 ที่ Host/Join ยังใช้อยู่ (เลเวลข้ามรอบ ฯลฯ) — ข้อ 3 ใช้กับ loop เท่านั้น เพราะ mptest ต้องผ่าน
- ร้านค้า/crafting/NPC/บทสนทนา (vision "ไม่ทำ")

## เกณฑ์เสร็จ (ต้องทำให้ได้ทั้งหมด)
1. ตายในโลกใหม่ → กลับฐาน → ที่เลือกโลกมี "โลกเก่า" 1 รายการ แสดงของที่ตกและเหลือ 3 ครั้ง
2. เข้าโลกเก่า → เห็นกองของที่จุดที่ตาย → เก็บคืนได้ (ตามช่องพก) → ฆ่าบอส → กลับฐาน → ของเข้าคลัง
3. โลกเก่ายากกว่าโลกใหม่ตามตัวคูณที่ยืนยัน
4. กลับฐาน 3 ครั้ง (รอดหรือตาย จากโลกไหนก็ได้) → โลกเก่าสลาย ของหายถาวร มีข้อความแจ้ง
5. ตายซ้ำในโลกเก่า → ของรวมเข้ากองเดิม ไม่ซ้ำซ้อนเป็นหลายโลก
6. ปิด-เปิดเกม → โลกเก่าและตัวนับยังอยู่ตามเดิม; เซฟ phase 1 เดิมเปิดได้
7. build ผ่าน, selftest 0 FAIL (เคสใหม่: ตาย→โลกเก่า, เก็บคืน, หมดอายุ, ตายซ้ำ, เซฟ/โหลด, เซฟเก่า), mptest ผ่านเหมือนเดิม
8. ไฟล์เอกสารแต่ละไฟล์ ≤ 10KB
