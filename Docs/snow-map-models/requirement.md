# requirement: โมเดลสวยของแมพหิมะ + นำเข้าเกมเป็น biome สุ่ม
ผู้ขอ: พีท (372330922122674179) วันที่ 2026-10-16
เกม: medieval-knight | สถานะ: ร่าง รอพีทยืนยัน
ต่อยอดจาก Docs\world-map-preview\ (blockout รอบแก้ 7 อนุมัติแล้ว)

## เป้าหมาย
ยกระดับ blockout ของแมพโลก (ทุ่งเขียว → หิมะ) เป็นโมเดลสวย แล้วนำเข้าเกมเป็น "หนึ่งโลกใน biome สุ่ม"

## ขอบเขต: เฉพาะโมเดลของแมพ
ภูมิประเทศ ทางเดิน/ทางน้ำแข็ง สะพาน หมู่บ้าน ปราสาทน้ำแข็ง ต้นไม้ หิน น้ำ ของประกอบ
(ไม่รวมตัวละคร/เอฟเฟกต์/ศัตรู)

## สไตล์
- Stylized low-poly ที่ละเอียดและสวยขึ้น ปรับแนวสไตล์ได้ตามเหมาะ
- ถ้าปรับสไตล์/จานสี ให้ปูส้มอัปเดต Docs\style.md และแจ้งพีท (สีใหม่ต้องได้อนุมัติ)

## เงื่อนไข
- ผลลัพธ์เป็นขั้นตอน: (1) โมเดลสวยใน Blender → export .fbx + preview.png/preview_top.png ให้พีทอนุมัติ
  (2) แล้วค่อยนำเข้าเกมเป็น biome สุ่ม (ผ่าน architect ก่อน)
- ขนาดแมพไม่เกิน 380x380 ม. (ของเดิมในแมพนี้)
- ใช้ pipeline ใหม่ของ asset: Art_kit\approved.md ตามขั้นตอน "นำ asset เข้าเกม"
- ออนไลน์ co-op ต้องไม่พัง (mptest ผ่าน) โลกเดียวกันทุกเครื่องจาก seed
- เพดาน tri และรายงานทรัพยากร: แจ้งก่อนถ้าเกินของเดิม (220,000 tri)

## ไม่เอา
- ไม่ทำ NPC/เควสต์ ไม่แตะโลก biome อื่น ไม่เปลี่ยนตัวละคร

## ข้อสมมติ (พีทแก้ได้)
- แมพหิมะเป็น biome เดียวในรอบนี้ biome อื่นไว้ทีหลัง
- ทางเดิน/ตำแหน่งตามที่อนุมัติแล้วใน world-map-preview คงเดิม เปลี่ยนแค่คุณภาพโมเดล
