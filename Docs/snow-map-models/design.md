# design: ยกระดับโมเดลแมพหิมะ (snow-map-models)
อ้างอิง: requirement.md, world-map-preview/design.md + decisions.md (รอบแก้ 7), style.md
ขอบเขต: โมเดลสวยใน Blender → export .fbx + preview.png/preview_top.png ขออนุมัติ (ยังไม่เข้าเกม)

## 1. เป้าหมายผู้เล่น
เดินจากหมู่บ้านต้นทางผ่านทุ่ง ป่าสน หน้าผา ไปถึงปราสาทน้ำแข็ง แล้ว "รู้สึกว่าเป็นโลกที่มีชีวิตและสวย" ไม่ใช่กล่องหยาบ
มองจากกล้อง top-down เอียง 56 องศา (ระยะไกล) ต้องอ่านรูปทรงออกทันที: ซิลูเอตชัด สีแยกชั้น (พื้น/ทาง/ของประกอบ)
เส้นทาง ตำแหน่ง ผังโซนที่พีทอนุมัติแล้วไม่เปลี่ยน เปลี่ยนแค่คุณภาพโมเดล

## 2. หลักสไตล์ (ปรับจาก faceted เดิม)
- ยังเป็น stylized faceted low-poly flat shading สีล้วนต่อ face ไม่มี texture ไม่มี outline (ตาม style.md)
- ปรับ: "ละเอียดขึ้นแบบมีเจตนา" = เพิ่ม silhouette (หลังคาซ้อน ชายคา ยอดแหลม กิ่งสน) + bevel ขอบ + รายละเอียดชิ้นเล็ก (หมุด ห่วงเหล็ก คาน) ไม่ใช่เพิ่ม poly เฉยๆ
- ทุกชิ้นเอียง/บิดนิดๆ 1-3 องศา ไม่มีเส้นตรงเป๊ะ ขนาดซ้ำใช้ 3-4 variant (ขนาด/หมุน/เอียงต่างกัน) กันดูซ้ำ
- หิมะ: ชั้นหิมะ "ก้อนนุ่มหนา" ทับขอบหลังคา/กิ่งสน/หิน (ใช้ #EEF3F8 ด้านรับแสง #C9D8E8 ด้านหลบ)
- vertex color / สีต่อ material ตามจานสี ไม่มี gradient texture; ใช้ material จำกัด (ต่อสี) เพื่อ batching ในเกม
- ระยะมอง: ชิ้นเล็กกว่า 0.5 ม. ไม่ต้องใส่รายละเอียดเกินสี 1-2 face

## 5. รายละเอียดต่อหมวด (จุดที่ต้องดีขึ้นเทียบ blockout รอบ 7)
- **ภูมิประเทศ**: facet ใหญ่สลับโทนหญ้า 3 สี (#8DB04A/#6C8535/#A0B85B) ไม่ซ้ำ pattern; ขอบหิมะ-หญ้าเป็นก้อนหิมะโค้งนูน ไม่ใช่เส้นรอยต่อ; หน้าผาเป็นขั้นหินเหลี่ยมมีร่อง; รักษาความราบโซน A/B (รอบแก้ 4)
- **ทาง**: กว้าง 4-6 ม. ขอบหยัก หย่อมหญ้า หินแผ่นฝัง; ทางน้ำแข็ง 5-7 ม. สีน้ำแข็งเด่นกว่าพื้นหิมะ ผนังขั้นเข้ม #6FB8D6; ตำแหน่งตามเดิมทุกจุด
- **สะพาน**: ไม้โค้ง ราว เสาหัวสะพาน แผ่นไม้แยกชิ้น หมุดเหล็ก ปลายสะพานต่อพื้นพอดี ตามทิศทาง
- **หมู่บ้านต้นทาง (25,25)**: บ้านชายคายื่น หลังคาสูงชันปลายงอ ปล่องมีหมวก, ควัน (ระนาบเหลี่ยมซีด), หน้าต่าง emission #F5C25A, ไม้มีคานตัดกัน; กังหันใบพัด 4 ใบ มีโครงไม้
- **ปราสาท**: ซิลูเอตแหลมเอียง ไม่สมมาตรเป๊ะ ผนังน้ำแข็งเข้ม-อ่อนสลับชั้น ยอดหอมีหิมะ, ธงแดง/ม่วงเทา, หน้าต่างโค้ง emission
- **ต้นไม้/หิน**: สนมีชั้นกิ่งเอียง ปลายกิ่งหิมะ; หินมีหิมะทับด้านบน ฐานมีหญ้า/หิมะเล็ก
- **น้ำ**: น้ำตกแผ่นเหลี่ยม 4 ชั้นสลับ #1594BB / #BFE6F2 + แอ่งโฟมขอบ (face สีขาวหิมะ); ทะเลสาบน้ำแข็งขอบหยักมีแผ่นน้ำแข็งลอยเล็กน้อย

## 6. Export และ asset (สำหรับ pipeline Art_kit\approved.md)
- 1 ชิ้นต่อ .fbx (ชุด variant ใส่ไฟล์เดียวแยก object ได้ถ้าเป็นตระกูลเดียวกัน) ตั้งชื่อ `snow_<หมวด>_<ชื่อ>_<vNN>.fbx` เช่น `snow_tree_pine_v01.fbx`
- หน่วยเมตร, forward -Z / up Y ตามที่ Unity import (apply transform ทุกชิ้น), pivot ที่ฐานชิ้น
- สี = material ต่อสีจานสี (ชื่อ material = ชื่อสี เช่น `snow_light`) ใช้ได้ทั้ง vertex color เสริม; emission เฉพาะหน้าต่าง/ไฟ/โคม
- ภูมิประเทศ: แบ่ง chunk ราว 95x95 ม. (4x4) เป็น .fbx แยก ชิ้นละ ≤ 4,000 tri เพื่อ cull/static batching
- ชิ้นซ้ำเยอะ (สน หิน พืช) export 1 ชิ้นแล้ววางซ้ำ — ไฟล์ layout (ตำแหน่ง) บันทึกใน .json หรือ .blend เพื่อให้ developer วางด้วย seed ตามเดิม
- ห้ามมี texture, ห้ามเกิน 1 UV set; ไม่ต้องมี rig/animation (กังหันหมุนด้วยโค้ด: แยกใบพัดเป็น object ต่างหาก pivot กลางแกน)

## 7. ขนาดและ layout ที่ล็อก
- พื้นที่ 380x380 ม. ไม่เกิน; พิกัดโซน เส้นทาง waypoint (ไม่แสดงใน preview) สะพานทั้ง 3 ตำแหน่ง น้ำตก ปราสาท (340,340) ตามเดิม
- เอาออนไลน์: โลกเดียวกันจาก seed — ทุกชิ้นวางด้วยตำแหน่งตายตัว/seed ไม่มีสุ่มใน Blender ที่เปลี่ยนต่อเครื่อง
- ลานกลาง (190,190) ยังโล่ง; หมู่บ้านอยู่ SW (25,25) ไม่ทับทางเดิน ไม่มีสะพาน S2/S3 ต่อทาง (รอบแก้ 7)
