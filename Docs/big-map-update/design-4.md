### 6.2 ช่องดาบ

- ดาบ 5 เล่ม = 5 ช่องเรียงแนวนอนตามลำดับเดิม ช่องละประมาณ 118 x 190 px
- **ไอคอนดาบ**: ภาพสี่เหลี่ยมจัตุรัส 128 px พื้นหลังทึบสีเดียวกับพื้นช่อง (0.12, 0.12, 0.17) ดาบเฉียง 45 องศาตายตัว ไม่หมุน (เรนเดอร์โมเดลจาก `Weapons.BuildModel` ลง RenderTexture ตามที่ architect วางไว้) ช่อง EQUIPPED ใหญ่ใช้ไอคอนเดียวกัน
- กรอบช่องตามความหายาก: Common เทา `#B0B0B0`, Uncommon เขียว `#5FCF6B`, Rare แดง `#D94A4A`, Legendary ทอง `#FFC93C`
- **ระดับ +N** ป้ายมุมขวาล่าง (+5 = "+5 MAX")
- **ช่องที่ใส่อยู่**: กรอบเขียวสว่างหนา + แถบ "EQUIPPED" + ติ๊กมุมซ้ายบน
- **ดาบที่ยังไม่มี**: ไอคอนเดิมย้อมมืดเป็นเงา + "?" ตัวใหญ่ (ใช้การย้อมสี); โฮเวอร์แล้วบอกที่มา (`dropHint` เดิม)
- โฮเวอร์ช่องที่มี: ข้อมูลพรีวิวในกล่อง EQUIPPED พร้อมลูกศรเทียบ **[เสนอเพิ่ม]**

### 6.3 วิธีเลือกใส่

| วิธี | ผล |
| --- | --- |
| กด 1-5 | ใส่ดาบช่องนั้นทันที (ถ้ามี) ไม่มี = Notice "X not found yet - <ที่มา>" |
| คลิกซ้ายที่ช่อง | ใส่ดาบ (ถ้ามี) เมาส์โฮเวอร์ช่องสว่างขึ้น |
| ลูกศร/A D + Enter | **[เสนอเพิ่ม]** เลื่อนเลือกแล้วใส่ |
| ช่องที่ใส่อยู่แล้ว | ไม่ทำอะไร |
| ใส่สำเร็จ | โมเดลดาบในมือเปลี่ยนทันที, Notice "Equipped <ชื่อ>", กรอบ EQUIPPED ย้ายพร้อมวาบสั้น |
