## 7. Soul

- **ได้อะไร**: ฆ่ามอนสเตอร์ = Soul เป็นแต้มสะสม (ตายแล้วไม่หาย) ตัวเล็กได้น้อย ตัวแดง/Minotaur ได้มาก (ตัวเลขเป็นของ architect; หุ่นฟางไม่ให้) รอบนี้ไม่มีที่ใช้
- **แสดงที่ไหน**: HUD หลักแถวล่างสุดของแผงซ้ายบน (ไอคอน + ตัวเลข ไม่มีแถบ) และมุมซ้ายล่างของคอลัมน์ CHARACTER ใน Tab
- **Feedback**: popup "+12 Soul" สีฟ้าขาว `#9FE8FF` ลอยเหนือศัตรูที่ตาย (เล็กกว่าตัวเลขดาเมจ); อนุภาคฟ้าขาว 4-6 ชิ้นลอยขึ้นแล้วพุ่งเข้าหาตัวอัศวิน; ตัวเลข Soul บน HUD เด้ง 1.2 เท่า 0.3 วิ; ไม่มีเสียงเฉพาะ ไม่มี Notice
- หลังตาย Soul ยังอยู่

## 8. อาหาร

- **2 ชนิด** (ดรอปจากมอนสเตอร์ มีโอกาส; ตัวเลขโอกาสเป็นของ architect):
  - **Apple**: แอปเปิลแดง low-poly (ก้อนกลมแบนเล็กน้อย + ก้านน้ำตาล + ใบเขียวเล็ก) ฟื้น 15% ของ MaxHp วงแหวนใต้ไอเทมสีเขียวอ่อน
  - **Roast Meat**: ขาย่างทรงรีสีน้ำตาลทอง + กระดูกขาวสองปลาย ฟื้น 40% ของ MaxHp วงแหวนสีส้มอุ่น
  - ลอยสูง ~0.4 ม. หมุนช้า เด้งเบาๆ มีเงา; เล็กกว่าดาบที่ตก (~0.5 ม.) และไม่มีลำแสงสี (ไม่สับสนกับดาบ)
- **Minotaur ดรอป Roast Meat 2 ชิ้น**
- **เก็บ**: เดินเข้าใกล้ ~1.25 ม. ไม่ต้องกดปุ่ม
- **Feedback ตอนเก็บ**: ไอเทมหาย + อนุภาคตามสีวงแหวนรอบตัว + popup สีเขียว `#5FE08A` **"+N HP" เป็นตัวเลขที่ฟื้นจริง** + แถบ HEALTH เติมพร้อมวาบ + เสียงเดิมเบาๆ (`knight_ready` volume ต่ำ)
- **ตอนเลือดเต็ม**: ไม่เก็บ ไอเทมยังอยู่ เดินผ่านเฉยๆ; ครั้งแรกที่เข้าใกล้มี popup เทาเล็ก "HP full" (ไม่ซ้ำทุกเฟรม)
- **อยู่บนพื้น 60 วินาที กะพริบ 8 วินาทีสุดท้าย**
- **ออนไลน์**: ใครเดินทับก่อนได้ ข้ามคนที่เลือดเต็ม (ของกลาง ไม่ใช่รายคน); คนที่ตายอยู่เก็บไม่ได้; popup เห็นเหนือคนที่เก็บ

## 9. ตายแล้วรีเซ็ต: หน้าจอตายและตอนฟื้น

### 9.1 ตอนตาย (layout หลัก)

```
+----------------------------------------------------------------+
|  (ฉากมืดลงเป็นสีแดงเข้มจางลงดำ ภายใน 0.6 วิ)                    |
|                       Y O U   D I E D                          |
|        You lose:   Lv 12  >  Lv 1                             |
|                    all upgrade cards and stat points           |
|        You keep:   Swords (4 / 5)      Souls 1,240             |
|                  Returning to town in  3 ...                   |
+----------------------------------------------------------------+
```

- YOU DIED สีแดง `#C42B2B` ~60 px; "You lose" เทาอ่อ; "You keep" ทอง/ฟ้า (Soul ฟ้าขาว)
- ตัวเลขที่แสดงคือค่าก่อนตาย รีเซ็ตจริงตอนฟื้น
- **เวลาฟื้นเล่นคนเดียว 3 วินาที** (ออนไลน์ 5 วินาทีตามเดิม) เป็น layout หลัก
- คนเดียว: เต็มจอ ปุ่มอื่นใช้ไม่ได้ยกเว้น Esc/F5; ออนไลน์: ฉากมืดน้อยกว่า ดูเพื่อนสู้ต่อได้ มีบรรทัด "Returning in 5 ..."

### 9.2 ตอนฟื้น

- ฟื้นที่ลานเมือง เลือด/เกราะ/stamina เต็ม Lv 1
- **สไลม์ในรัศมี 60 ม. รอบจุดเกิดถูกลบ และกล้อง snap ไปที่จุดเกิด**
- ภาพ: ฉากสว่างเร็ว ตัวอัศวินวาบฟ้าขาว
- Banner 1.6 วิ: **"Revived - back to Level 1"** + เสียง `knight_ready`
- HUD: LV เป็น "LV 1" วาบ แถบ EXP ว่าง
- ถ้าตายตอนหน้าต่างเลเวลอัป/Tab เปิด: ปิดทันที แต้มค้างถูกล้าง
- F5 = รีเซ็ตทั้งเกมแยกจากตาย (ล้าง Soul ด้วย ดู Q2)
