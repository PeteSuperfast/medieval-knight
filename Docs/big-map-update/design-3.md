Minimap: 170 x 170 px มุมขวาบน พื้นสีตามโซน ขอบทอง `#BFA050`; ผู้เล่น = ลูกศรขาว; เพื่อนออนไลน์ = จุดสีตาม pid (นอกขอบเป็นลูกศรที่ขอบ); ไอคอนเมือง/รังคงที่; ซูมราว 140 ม.; แผงปุ่มเลื่อนลงใต้ minimap (-16,-196)

### 4.2 สิ่งที่เอาออก / คงไว้

- **เอาออกจากจอ**: ผลรวมอัปเกรด (damage / atk speed / crit ต่อสกิล), บรรทัด SWORD, บรรทัด POINTS, บรรทัดแต้มที่ยังไม่ใช้, ป้ายต้นทุน stamina ในไอคอนสกิล, บรรทัด Wave / Slimes / Kills → ย้ายไปหน้า Tab (เฉพาะ Kills; ไม่แสดง Wave)
- **คงไว้**: HEALTH, ARMOR, STAMINA, LV+EXP, ไอคอนสกิล 4 อัน, แถบบอส, party list (ออนไลน์)
- ถ้ามีแต้มสเตตัสค้าง → ป้าย "TAB !" กะพริบเหลืองข้างตัวเลข LV

| แถบ | สี | ขนาด / ตำแหน่ง |
| --- | --- | --- |
| HEALTH | แดง `#DB3333` | กว้าง 288 สูง 24 ที่ (116,-28) ซ้ายบน เหมือนเดิม |
| ARMOR | ฟ้า `#80ADEB` | (116,-60) |

| SOUL | ตัวเลขฟ้าขาวเรืองแสง `#9FE8FF` + ไอคอนหยดวิญญาณ | แถวที่ 5 (116,-156); แผงสูง 146 → ~180 |
| ลูกศร Lair | ลูกศรขาวขอบทอง + ตัวเลข "Lair 143 m" สีทอง 15 px | ใต้แผงซ้ายบน (28,-190) |

### 4.4 หลอด Stamina (ใช้กับ dash เท่านั้น)

- แถบเดิม เพิ่ม **ขีดแบ่งแนวตั้งบางๆ ทุก 25 หน่วย** (1 dash = 25) ผู้เล่นเห็นว่า dash ได้กี่ครั้งโดยไม่ต้องอ่านเลข (เลข `80 / 96` ยังอยู่)
- ใช้แล้วมี ghost bar ตามเดิม; ฟื้นเองเรื่อยๆ
- ฟื้นพอ dash ได้อีก: ขีดช่องนั้นวาบสว่าง 0.15 วิ
- ท่าดาบ สกิล โล่ ไม่ลดแถบนี้ (แถบนิ่งตอนฟันเฉยๆ ถูกต้อง)
- stamina ไม่พอ → ดู 5.2

## 5. ปุ่มใหม่และ feedback ของ dash

### 5.1 ตารางปุ่มทั้งหมด

| ปุ่ม | หน้าที่ | เปลี่ยนจากเดิม |
| --- | --- | --- |
| W A S D / ลูกศร | เดิน | เหมือนเดิม |
| เมาส์ | เล็ง (หันตามเคอร์เซอร์) | เหมือนเดิม |
| **Left Shift ค้าง** | **วิ่ง** x1.5 ไม่กิน stamina | เดิม = ยกโล่ |
| **Space** | **Dash หลบ** อมตะ 0.5 วิ (กิน stamina 25) | เดิม = ฟันดาบ |
| คลิกซ้าย / J | โจมตี คอมโบดาบ | เดิม: + Space |
| **คลิกขวา ค้าง** | **ยกโล่ อย่างเดียว** | เดิม: + Left Shift |
| Q / E / R / F | สกิล (ไม่กิน stamina) | ไม่กิน stamina แล้ว |
| 1 / 2 / 3 หรือคลิกการ์ด | เลือกอัปเกรด แล้วเลือกแต้มสเตตัส | เหมือนเดิม |
| **Tab** | เปิด/ปิดหน้าต่าง Inventory + Stats | เดิม = I (**I ยกเลิก**) |
| ในหน้าต่าง Tab: 1-5 / คลิกช่อง | ใส่ดาบเล่มนั้น | เหมือนเดิม |
| M / F1 / H / F5 | ระดับเสียง / ซ่อนแผงปุ่ม / ทดสอบโดนตี / เริ่มใหม่ (ออนไลน์: host) | เหมือนเดิม |
| Esc | **ถ้า Tab เปิดอยู่ = ปิดหน้าต่าง Tab ก่อน (ไม่นับเป็น Esc ออกเมนู)**; ไม่งั้นกดสองครั้ง = เมนู | ปรับ |

กติกา dash (ตาม tech.md):
- ระยะ 6 ม. ใน 0.2 วิ, อมตะ 0.5 วิ (ยังอมตะต่อหลังหยุดพุ่ง), cooldown 0.8 วิ
- ทิศ: ตามที่กด WASD; ไม่กดทิศใด = ถอยหลังจากเคอร์เซอร์
- dash **ยกเลิกท่าฟัน / สกิล Q E R ได้**; **ห้าม dash ตอน Ground Slam (F) กลางอากาศ**
- dash ตอนยกโล่: ปิดโล่ระหว่าง dash แล้วยกต่อถ้ายังกดคลิกขวาค้าง
- ยกโล่ตัดสถานะวิ่ง (วิ่งไม่ได้ขณะยกโล่)
