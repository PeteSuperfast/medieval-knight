# Style Guide — medieval-knight
ภาพอ้างอิงอยู่ใน Docs\ref\ ใช้จับ "แนวรวม" เท่านั้น ห้ามลอกรูปทรงของชิ้นใดชิ้นหนึ่ง

## แนวหลัก: Stylized faceted low-poly (ฉากและของประกอบ)
อ้างอิง: env_tower, env_nature_kit, env_forest_scene, env_rocks_trees, prop_fence_barrel, prop_plants, prop_palms
- รูปทรงเหลี่ยมเห็น facet ชัด flat shading ไม่มี texture ลวดลาย ใช้สีล้วนต่อ face
- สัดส่วนเกินจริงแบบน่ารัก: หลังคา/หมวกใหญ่ สูงชัน ปลายงอ, ต้นสนเป็นชั้นๆ ซ้อนกัน, ทรงพุ่มกลมเป็นก้อน
- ไม่มีเส้นตรงเป๊ะ: อาคารเรียวหรือเอียงเล็กน้อย, ไม้ระแนงบิดนิดๆ, ขอบลบมุม (bevel) เล็กน้อย
- รายละเอียดเล็กๆ ช่วยให้มีชีวิต: เห็ด, ก้อนหิน, หญ้ากระจุก, ทางเดินหินแผ่น, ควันจากปล่อง
- ไม้มีรอยแตกและหมุด, ถังไม้มีห่วงเหล็กสีเข้ม
- เกาะลอย/ขอบพื้นที่ตัดให้เห็นชั้นดินด้านข้าง ใช้ได้กับฉากที่ต้องการโชว์

## แสงและบรรยากาศ (สำคัญพอๆ กับโมเดล)
- แสงหลักอุ่น เฉียงจากด้านข้าง เงานุ่มทอดยาว
- ท้องฟ้าไล่สีฟ้าอมม่วงไปชมพูพาสเทล
- หน้าต่าง/ตะเกียงเรืองแสงสีเหลืองส้ม (emission) ให้ฉากอบอุ่น
- post-processing: bloom อ่อน, ambient occlusion, color grading อุ่นเล็กน้อย

## ตัวละคร (อ้างอิงแนวเท่านั้น)
อ้างอิง: char_skeleton, char_golem, char_dwarf, char_ratfolk
- faceted low-poly เดียวกับฉาก สัดส่วนบึกบึน มือเท้าใหญ่ หัวใหญ่
- สีหม่นกว่าฉากเล็กน้อย ใช้โทนน้ำตาล/หิน/กระดูก
- ศัตรูแบบ "ชิ้นส่วนแข็ง" (golem หิน, skeleton, หุ่นฟาง) ทำได้ด้วยชิ้นส่วนแยก
  ขยับด้วยโค้ดใน Unity โดยไม่ต้อง rig
- ตัวละครที่ต้องมี animation ซับซ้อน (อัศวินผู้เล่น) ใช้ asset pack แล้วปรับสีให้เข้าจานสีนี้

## ไม่ใช้
- voxel/pixel, realistic texture, งานมืดหม่นแบบ PS1, สีสะท้อนแสงจัด, outline
